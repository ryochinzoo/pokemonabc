## 5. ★踏むな(今日実際に踏んだ)

1. **ゴールポストを動かすな。** 判定を「差>MDE」から「CI下限>0」に変え、
   **「MDEはN依存だがCI下限>0はN非依存だから訂正」と書いた。数学的に誤り** —
   `CI下限>0` は `d > 1.96×SE(N)` で同じくN依存。承認基準の**56%緩和**で、
   **前日「基準未達」で見送った +1.38pt が新基準なら「提出」になっていた**。
   **真にN非依存なのは D29 の +2.0pt だけ。**
2. **小さいNから乖離を語るな。** 今日2回踏んだ:
   ①N=12 のオーロンゲ(16.7%)から「族内は26pt甘い」→ N=200 で 39.0%、乖離は消えた
   ②1回のトレース(Δ=14、Poisson SE≈15.7)から「VETOは10.7%削る」→ 実測 0.62pp±0.83pp
3. **`bash -n` は実行時エラーを捕まえない。** macOS の bash は **3.2** で
   **`declare -A` が使えず**、`set -u` 下で空配列 `"${opp[@]}"` も落ちる。
   → `${arr[@]+"${arr[@]}"}` を使う。`"${arr[@]:-}"` は空文字列を1個渡すので不可。
4. **`driver.log` を grep して集計するな。** 再開すると同じセルが二重計上される。
   → `results.tsv` に (腕,セル,ブロック) キーで書き、集計側で重複排除する(実装済み)。
5. **JP_Card_Data.csv は列名も日本語**。両CSVとも **UTF-8 BOM 付き**(`utf-8-sig` が要る)。
6. **T7 は3回連続で私の誤りを止めた。** レンズを分けた独立レビュア3本を Agent で並列に回す。
   `/t7-panel` ワークフローは壊れているので使わない。
