## 1. なぜ再審に値するか(D32「新証拠がある場合のみ」の充足)

kill 後に実施した3件の解析。いずれも kill 時点では未計算だった。

**(a) ゲート③の作動特性が壊れている(D29の誤り類型の再生産)**
「対照セルで誤特定率の点推定が増えたら中止」は、両腕N=50・真の差ゼロのとき
**44.2%の確率で発火**する(真p=0.10〜0.20のいずれでも43〜45%、同値10〜13%)。
これは D29 が廃止した「非退行4ゲート(偽陽性65.1%)」と**同じ構造の欠陥**であり、
起案者(cc)が自分で書いた登録文に混入させた。台帳#10/#22の系列に連なる自己監査事例。

**(b) 実測差はノイズ**: 7/50 vs 9/50、**Fisher両側 p=0.786**。

**(c) ★決定的 — ゲート③が検出しようとした機構は、実測で発生しておらず、かつ観測された方向に
介入が寄与することは構造的に不可能**:
- 新4エントリが辞書外デッキ(壁)を奪取した回数 = **0/50**。
  変種側の誤キーは全9件が**旧エントリ `kangaskhan_crustle`**(champion側は5件)。
- `_infer_enemy_deck` は `if score > best_score` の逐次 argmax で、新4エントリは
  **辞書の先頭**に挿入されている(任意#3)。よって `kangaskhan_crustle` は新4件の**後**に
  評価され、評価時点の running max は新エントリ追加によって**同じか大きくなる**。
  → **介入は kangaskhan の選択回数を減らすことしかできず、増やすことは原理的に不可能**。
- したがって観測された 5→9 の増加は**介入では説明できず**、非対応標本の揺らぎのみが原因。
  ゲート③は「自分が測れないもの」で発火した。

**結論**: ゲート③の**目的**(新エントリが計器外デッキを奪う=カバレッジ外リスク)は
0/50 で満たされていた。**letter は fail、purpose は pass**。そして letter 側の判定装置は
44%の偽発火率を持つ壊れた計器だった。
