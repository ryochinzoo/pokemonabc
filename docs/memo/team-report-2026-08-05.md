## 1. 背景 — スターミーの限界と、いまのメタ

### スターミー(現王者、確定レート783/793.9)の測定された限界

- **レート700を超えた瞬間に勝率が52%→41%に落ちる**(帯別の実測)。負け筋はブリジュラス16.7%・ミラー0勝3敗・上位のメガルカリオ。
- **「語れる要素」が測定した全デッキ中最少** — 中身はこう(すべて実測):
  - **特性0個・スタジアム0枚・妨害/回収/ダメージ操作カード0枚**(上位勢はクラッシュハンマー、マシマシラのダメカン移動、夜のタンカ等の「個性札」を毎試合回している)
  - 1試合に使うカード**12.9枚**(上位勢15〜23)/ カードの種類**11**(同12〜16)/ 攻撃するポケモン**2種**(同3〜4)/ よく使うカード上位5枚が**全部汎用のサーチ・ドロー**
  - デッキが呼び出すゲーム機構の数を数えた指標で**12本中最下位**(40点、中央値68)
- なぜこれが問題か: 審査のDeck 20%は「構築の判断」を見る。**判断が発生する機構が少ない=記事に書ける判断が少ない**。運営も「deckcrafting(デッキ構築)」を名指しで評価軸に挙げている(§2)。スターミーは「エンジンの穴を突いた合理的なデッキ」だが、**記事の主役としては構造的に弱い**。

### メタの分析(全対戦ログをレート付きで集計。この形のデータは公開範囲で我々しか持っていない)

レート800-1099帯の顔ぶれ: **フーディン29.2% / オーロンゲ19.3% / イワパレス13.5% / メガルカリオ13.2% / ブリジュラス10.7%**。

ここで重要な発見: **このメタは「強さ」で並んでいない**。

- 使用率と勝率の相関はほぼゼロ(ρ=−0.02)。最多のフーディンは勝率ワースト3。
- **オーロンゲは723チーム中505チーム(69.8%)が完全に同じ60枚**。公開コードは0件(公開ノートブック291件を全部実行して確認)なのに788チームいる=**公開リプレイからの模倣学習で量産されている**。8位のJakeも「データが大量にあるから作りやすい」と証言。
- つまり**メタは「コピーしやすさ」で決まっている**。たった2種類の同一リストが全チームの35.6%を占める。

### だから何をしたか

パイロット(main.py)を1バイトも変えず、deck.csvだけ差し替えて勝率を測る実験をした。**デッキだけで勝率が最大60pt動いた**(パイロット側を7ヶ月改良して得た最大値は+13.6pt)。**デッキ選びのほうが4倍効く**。そして記事審査もデッキ構築を要求している——**デッキ転換はSimと記事の両方に効く**、が転換の根拠。

## 4. 分析の結果わかったこと(要点5つ)

1. **メタは「コピーしやすさ」のシステム**。標準化された実物リストに対して実測で選ぶのが最強の選定手段。
2. **デッキとパイロットの相性は、少数の「盲点」に集約される**。3系統を特定: ①特性で得た資源の配り先を考えない(修理したら+13〜20pt) ②山札を削る特性を毎ターン押して自滅 ③ダメージがカードのテキストにしか書いていない技を0点と評価してしまう。
3. **他人が使って強いデッキが、我々のパイロットで強いとは限らない**(実測で−23pt〜+42ptまで両方向にズレた)。選定は必ず「我々のパイロットを載せた実測」で。
4. **セルフ対戦は当てにならないと分かり、測定を「外部の実物」相手に全面転換した(←重要な方法論の変化。共有)**: 自分のパイロット同士の対戦で測る勝率は、本物の相手との勝率より**+8〜+62pt甘く出る**と実測で判明している。以来、勝率の判定は全部**外部の実物エージェント**(公開されている他チームのagentを固定の練習相手にしたもの=§9の較正済みゲージ)か**本番ラダー**で行い、セルフ対戦は下書き確認用に格下げした。§7の「フーディンに11勝1敗」も本番の他チーム実物が相手。**りょーちんのローカル測定にもそのまま効く話**なので、勝率を語るときは§9の練習相手を使ってほしい。
5. **その練習相手にも嘘がある**(運営サンプルのメガルカリオ相手の勝率は、本物の上位プレイヤー相手より+45pt甘かった)。本番の実測と一致する練習相手に世代交代した。

### パイロット側の穴も本番で実測できた

- 主砲ロケットラッシュと反撃技ロケットミラーは、ダメージがテキストにしか書いていないため**パイロットの評価器には0点に見えている**(登録2行で直る)。
- 攻撃しないフリーザーにエネを毎試合1.7枚浪費。超エネの74%が型の合わない先へ。
- ミュウツーの「ロケット団4体いないと攻撃不可」条件を見ずに前に出す。

### 何が足りないと分析したか

2. **ミュウツーexのサイド負債の圧縮**(献上サイドの1/3)。
3. パイロットの**テキスト打点の登録(2行)と、エネの型を見た貼り分け**。
4. メガルカリオ対面は上の3つでも勝ち越せるか不明(構造的な速度差)——「捨て対面として管理する」判断もあり得る。
