## 1. 背景 — スターミーデッキの限界と、いまのメタ

### スターミー(現王者、確定レート783/793.9)の実測された限界

- **700点を超えた瞬間に勝率が52%→41%に落ちる**(帯別実測)。負け筋は Archaludon 16.7% / ミラー0-3 / 上位Lucario。
- **「語れる要素」が測定した全デッキ中最少**: 1試合に使うカード12.9枚(上位帯は15〜23)、カード種類11、
  攻撃役2種、スタジアム0、特性0、妨害・回収・ダメージ操作カード0。表現力指標DEXで12本中最下位(40、中央値68)。
- 運営は評価軸に **deckcrafting を名指し**している(§2参照)。スターミーは「エンジンの穴を突いた
  合理的なデッキ」だが、**Deck 20%と記事の主役としては構造的に弱い**。

### メタの分析(レーティング付き全譜 = 我々にしか作れない計器で実測)

800-1099帯の構成: **Alakazam 29.2% / Grimmsnarl 19.3% / Crustle 13.5% / Lucario 13.2% / Archaludon 10.7%**(distinct提出数で検証済み)。

ここで重要な発見: **このメタは「強さ」で並んでいない**。
- シェアと帯内勝率の相関 **ρ=−0.02**。最多のAlakazamは勝率ワースト3。
- **Grimmsnarlは723体中505体(69.8%)が完全に同じ60枚**。公開コードは0件(291件を実行して確認)なのに
  788体いる = **リプレイダンプからの模倣学習**で量産されている。8位Jakeも「データが多いから作りやすい」と証言。
- 逆にgarchompは公開評価が高くても素材が見えないので133体しか増えない。
- → **メタは「コピー素材の可視性」のシステム**。たった2種類の同一リストが全チームの35.6%を占める。

### それから(方針転換の根拠)

操縦者を固定してdeck.csvだけ差し替える実験で、**勝率が最大60pt動いた**(操縦者側7ヶ月の最大改善は+13.6pt)。
デッキ軸は操縦者軸の4倍広い。かつ上記の通り記事もdeckcraftingを要求している——**デッキ転換はSimと記事の両方に効く**。

## 4. 分析の結果わかったこと(要点)

1. **メタはコピー可視性のシステム**(§1)。標準化された実物リストに対する実測が最強の選定手段。
2. **デッキ×操縦者は分離できないが、結合点は少数の「盲点」に集約される**。3系統を特定:
   ①効果由来の資源配分(修理で+13〜20pt実証)②山を消費する特性の盲打ち ③テキスト内打点(damage欄0)。
3. **他人の操縦の実ラダー値は、我々の操縦者には双方向に転移しない**(−23pt〜+42pt)。
   選定は必ず「我々の操縦者を載せた実測」で行う。
4. **ゲージには嘘がある**: 公式サンプル由来のLucarioゲージは+45pt甘かった。実ラダーで検証済みの
   較正ゲージに世代交代した(P9の実測セルと14.0%≈15.4%で一致)。

### 6.1 選定の方法(重要: 構成は「設計」ではなく「輸入+選抜」)

**このデッキは我々が1枚ずつ組んだものではない。** 実ラダー800-1099帯の全譜からtarountula系101体の
リストを抽出し、**最も再現されている形(17体が完全一致の最頻出形)をそのまま輸入**した。
我々がやったのは構築ではなく**選抜**——操縦者を固定してdeck.csvだけ差し替え、5デッキ×4ゲージで
実測し、最高値(4面加重64.8%)を出したこれを選んだ。枚数の根拠は「実ラダーで最も使われている形」
という統計的根拠であって、カード単位の設計判断はしていない。**だから「なぜこのカードなのか」は
そのまま議論の余地であり、変更候補は§7の実戦データから既に出ている。**

## 7. 試した結果 — P9(本番ラダー53戦)の中身(レートではなく内容)

- **対Alakazam 11勝1敗(12体の別チーム)**: Repelling Veilが相手の主効果(ダメカン移動・こんらん)を
  完封。被ダメカン534個のうち保護対象への着弾は**Articuno不在ターンの54個のみ**=保護窓の破れゼロ。
  完全無効の試合が3本。**ローカルゲージ(94.5%)がそのまま本番に転移した**。
- **測れなかった暗部(Grimmsnarl/Crustle系=フィールドの32.8%)は7勝2敗**: Crustle壁はRocket Rushが
  非exなので素通しで4-0。ここはプローブでしか測れなかった(公開Grimmsnarl操縦者は0件と実行で確定済み)。
- **対Lucario 2勝11敗(13体)が敗因のほぼ全て**: 内容は**開発速度の完敗**——敗戦の我々の攻撃回数
  中央値2回 vs 相手6回、完封級が8/11。KOの82%はMega Lucarioの打点だが、壁テックは検討の結果**棄却**
  (非ex打点が13デッキ中12〜13に常備・壁は自身しか守らない・特性で剥がされる)。
- **tarountulaミラー1勝1敗**: 負けた相手は**改良変種(Ultra Ball/Mimikyu入り)**で、相手のRocket Rush
  4回に対し我々0回の完全な速度負け。**改良レシピは相手の山からそのまま読める**。
- **旧王者系統(Mega Starmie使い)に0勝2敗**という皮肉な結果も出ている。
- **操縦者の穴も本番で実測**: 主砲Rocket Rushと返し刃Rocket Mirrorが評価器に**打点0と見えている**
  (テキスト打点の未登録=2行で直る)/ 攻撃しないArticunoへのエネ浪費1.7枚/戦 / Mewtwoの攻撃条件
  (TR4体)を見ずに前に出す。

### 何が足りないと分析したか

1. **展開速度**(Rocket Rush=場の数×30なので、展開の遅れが火力・防御の両方を殺す)→ たね密度と
   ボール系(Ultra Ball等)の不足。
2. **Mewtwo ex負債の圧縮**(サイド献上の1/3)。
3. **操縦者のテキスト打点登録**(2行)と**型対応エネ配分**(Articuno磁石の解消)。
4. Lucario対面はこの3つでも天井不明(構造的速度差)——ここは「捨て対面として管理する」判断もあり得る。
