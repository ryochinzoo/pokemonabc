## 4. 判定規則(測定前に固定。Δ = CEW(B) − CEW(A))

**規則0(正当性ゲート、B側)** — 5ゲート。**FAILの確定で A×2**(D34前例):

| ゲート | 判定(M2/M4/M5で固定) |
|---|---|
| vs random | **点推定 x≥384/400 でPASS**。`bench.py --baseline` のexit 1(CI下限判定)は本ゲートの判定に使わない。境界帯(点推定<96% かつ Wilson95%CI上限≥96%)に限りN=400を1回だけ追試し、合算N=800でx≥768。単発OC: 真96%→FAIL≈45% / 97%→≈9% / 98%→≈0.1%、追試込みで真97%→≈4% |
| CRASH | **tracebackにB main.py(同梱モジュール含む)のフレームを含む例外のみBのCRASH**とし、それが1件でもあればFAIL。ゲージ/エンジン/ハーネス起因は計器故障=当該チャンクを1回だけ再走し件数と帰属を記録。**計器故障3件超は測定中断→パネル再協議**(BのFAILにしない) |

| check.py | PASS(トレーリングカンマはパーサ側で許容済み=M3) |
| conformance.py | PASS |

**規則2**: **Δ ≥ +2.0pt かつ 実測95%CIが0を除外** → 「Bを最終枠に含める」を**チーム合意に付議**。
- **付議パック(M10、事前固定)**: ①gauge Δ+CI ②**Bの実ラダー証拠(v7.x提出の検死等)を必須同梱**
  ③§3の計器限界①-④。**gauge Δと実ラダー証拠が矛盾した場合、推奨初期値はB×1+A×1ではなく
  A×2に戻し**、Bの繰上げは較正提出(T1予測つき検死)での解消を条件とする(A6: この較正提出枝は
  りょーちん同意+ゆうじ承認が前提の選択肢として記載)。

  最終構成の決定はゆうじ+りょーちん。
