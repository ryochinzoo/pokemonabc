## D6 (2026-07-07) 偵察の成果物は「デッキ名」ではなく「AIが回しやすいデッキの構造原理」とする
- **決定**: LB上位2強（Marnie's Grimmsnarl ex / Alakazam+Dudunsparce）から抽出した次の構造特徴を、デッキ選択と評価関数設計の共通理論として採用する。
  (a) **進化トリガー能力による1手圧縮**: デッキの最難関リソース（エネ/手札）が「進化」という単一行動の副作用で一括解決され、貪欲法がほぼ最適に一致する（Punk Up / Psychic Draw）。
  (b) **ダメージが決定的・線形**: コインなし、固定値 or 単一観測変数の一次関数（Shadow Bullet 180+30 / Powerful Hand 手札×20）。KO閾値を厳密計算できる。
  (c) **エネ逐次貼りの意思決定が消えている**: 1個で攻撃 or 一括供給。貪欲AIの典型的敗因（貼り先ミス）が設計上発生しない。
  (d) **勝ち筋が単線ループ**: 同型アタッカーの再生産。ゲームプランが決定木でなくスクリプト。
  (e) （Alakazam固有）**サイド非対称**: 非exの1枚サイドアタッカーがex(2枚)を狩る交換比。
- **理由**: デッキ名は8/16までにメタが動けば陳腐化するが、原理は「言語化→予測→実測検証」の科学の形にでき、Strategy審査の評価軸（分析・独創性）に直撃する。原理の予測力の実証として「第三の候補」= **Archaludon ex [190]**（1進化・進化トリガーでトラッシュからエネ2加速・固定220・被弱点消し）を実験対象とする。
- **状態**: 採用。原理(a)〜(e)は 2026-07-07 の cabt 実機検証で裏取り済み（→ journal / data）。

## D8 (2026-07-07) main.py v1: 貪欲ベース＋ダメージ評価のヒューリスティックを採用
- **仮説**: ランダム選択を「進化>能力>プレイ>エネ貼り>攻撃(ダメージ見積り最大・リーサル優先)>番を返す」の貪欲方針＋文脈別のCARD選択方針に置き換えれば勝率が上がる。
- **変更点の要約**:
  - ダメージ評価器: ワザ基礎値＋弱点×2/抵抗−30。**ダメカン乗せ（Powerful Hand等）は弱点・抵抗を通らない別レーン**で計算（D6の実機検証を反映）。スケーリングワザは補正表 `_SCALING_DAMAGE` で管理。
  - リーサル判定: 見積りダメージ >= 相手バトル場HP なら攻撃を最優先。
  - CARD選択: コスト系は「エネ>グッズ>サポート>ポケモン」の順に安く払う / サーチ系は「場の進化先>ポケモン>トレーナー>エネ」で取る / ダメカン配置は相手の低HP優先 / バトル場に出すのは「エネ付き>高打点>高HP」。
  - 堅牢性: 全分岐 try/except＋合法フォールバック。ATTACK/COUNT選択で minCount>1 でも契約を満たすようランク済みリストから k 個返す構造に修正。
- **結果**（同一デッキ・300戦）: 対ランダム **91.0%**（95%CI 87.2〜93.7%、GATE=PASS）。対Alakazamゲージ（デッキ込み・300戦）: **63.0%**（CI 57.4〜68.3%）— ランダム時代の25.5%から改善。CRASH=0。
- **状態**: 採用。スナップショットは `.bench/main_prev.py`。
- **注意**: 対Alakazamゲージの相手はスクリプトAI（リトリートしない等の弱点あり）なので「本物のLB上位への勝率」ではなく**下界の指標**として読む。

## D9 (2026-07-08) デッキは当面サンプル（メガユキノオーex）を維持。メタコピーは「操縦者の壁」で保留
- **実験**: 4デッキ総当たり（同一パイロット=v1、300戦/ペア）＋専用スクリプトAIゲージ2種との対戦。
- **判明した構造**: **デッキの強さは操縦者とセットでしか測れない。**
  - 同一パイロットの総当たりでは Archaludon型 が全ペア勝ち越し（Condorcet勝者、対サンプル55.0%）。
  - しかし**専用AIが操縦する**Alakazamゲージ相手だと Archaludon 40.0% < サンプル 63.0%。手札×20の実弾（280〜420点）に対し、HP300のArchaludonは一撃圏・HP350のメガユキノオーは僅かに圏外という差が効く。
  - Alakazamデッキをv1に持たせると自滅（v1は手札を使い切る方針なので「手札=打点」の勝ち筋を自壊）→ 手札温存ロジック（D案系）ができるまで凍結。
- **決定**: deck.csv はサンプル維持。Grimmsnarl型スクリプトAI（grimmsnarl_agent.py）を第2ゲージとして常備し、以後は**2ゲージ平均**を主要指標にする（現在: 対Alakazam 63.0% / 対Grimmsnarl 75.3%）。
- **メモ**: 2強ゲージ同士の直接対決は 50.3% とほぼ五分（LBで両者が共存する観測と符合）。
- **状態**: 採用。デッキ差し替えの再検討条件 = ①手札温存ロジック実装後のAlakazam型再測定、②Grimmsnarlゲージ強化後のArchaludon型再測定。
