# 4専門家評議会による統合計画 (2026-07-20)

戦略専門家・赤チーム批判者・ポケモンTCG専門家・プログラミング達人の4視点による
独立レビュー(全員が一次資料を直接読了)の統合。バイアス対策として、各自に既存決定
(D17含む)への遠慮を明示的に禁じた。個別報告の全文は本ファイル末尾の要約参照。

## 全員一致した結論

1. **最優先はv2.1cパッチ**: ライブ提出中のv2.1bに`string_at(NULL)`セグフォルト穴
   (try/except不能=対局没収)が現存。NULLガード移植は30分・挙動不変。→ **実装済み**、
   フルゲート後に再提出(要ユーザー承認)。
2. **汎用MCTS路線は終了**: 故障機序が説明された(下記)。iter4は「クラス限定上書き」
   アーキテクチャに転換、kill基準を事前登録。
3. **独自性の主砲は方法論**: 決定化MCTSは教科書(ISMCTS)で197本のwriteupに同型が複数出る。
   我々の差別化資産は (a)vs-randomが暴いた自滅バグと「攻撃的ゲージは自滅を隠す」
   (b)操縦者とデッキの非分離性 (c)対照実験付きで自説を棄却した負の結果
   (d)帯条件付きデッキ選択 — の方法論的発見群。
4. **測定の近親交配の解消**: 全ベンチの相手操縦者が自前パイロット。族外の物差し
   (公開steelエージェント, Apache2.0, 検証専用)で較正を1点取る。
5. **統計規律**: N=200(SE≈3.5pt)で3pt差の結論を語らない。効果量5ptの検出はN≈800を
   事前登録。8対面の符号一致(方向性)だけを堅い証拠として扱う。

## v3が壊れた機構(プログラミング達人の診断)

v2.1bの平坦探索は「全候補が同一の山札順・相手手札・v1継続方策を共有する**対標本の
差分推定器**」。評価関数の絶対値の歪みは差分で相殺され、マージン120は有意性検定として
機能する。v3はこれを3経路で破壊した:
- **A. 地平の盲目×露出増**: v1のドメインパッチ(山札温存・リトリート)はT+30の知識。
  T+2評価には見えず、分散膨張でマージンが実効無意味化→上書き率54%で害が露出。
  負け幅最大の対面(Alakazam/壁/Lucario)=パッチ依存対面と一致。
- **B. プーリング偏り**: MCTSの訪問数重み付き平均は決定化間の絶対値差(サイド項±10000)を
  候補比較に漏らす。iter2/3の統計修正で直らなかった観測と整合。
- **C. オフポリシー誤差**: 上書き率54%では実方策はもはやv1でないのに、ロールアウトは
  「以後v1」を仮定。誤差が複利で乗る。

## iter4設計(クラス限定上書き、実装~5.5h、総投下上限12h)

- 既定=v2.1b完全等価。探索の追加価値は「評価関数を信用しない順」に3層:
  1. **リーサル/ブランダー層**: ロールアウト中の終局検知のみで上書き(評価関数フリー)
  2. **クラス・ゲート層**: 上書きは許可リストのクラスのみ(retreat/attack_select/
     energy_target)。preserve_deck中とv1のABILITY/PLAY選択には拒否権(実証済みパッチ保護)
  3. prize-trade評価と相手カード累積記憶は個別フラグで単独検証後に昇格
- **シャドーモード**(V3_SHADOW): 上書きを記録するが適用しない=勝率を落とさず
  反実仮想の露出分布を無料収集
- 段階ゲート: Stage0対照(50%±)→Stage1 shadow→Stage2クラス単独ON(ミラー200で足切り→
  プール加重≥64%かつ最悪対面悪化≤5pt)→Stage3合成(加重≥65%+random≥96%+CRASH=0)
- **kill基準(事前登録)**: 7/24までに害分析で正寄与クラスが特定できなければ終了。
  8/2までにStage2未達なら凍結。8/2以降のv3新規開発は結果に関わらず禁止。
