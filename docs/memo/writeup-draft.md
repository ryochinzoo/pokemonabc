## 二重背骨 (R2③) — 各節でAとBを交互に打つ

- **背骨A(方法論)**: 計器を作る → 実ラダーで較正する → 前向きに予測させる →
  **判定規則そのものを監査し続ける**(偽陽性65%の規則を廃止→自らの+2pt閾値が約1.1σと
  暴いて再設計=D29→#22→D38の3段) → 自分の棄却判断の誤り(#12)まで較正計器で暴いて報告する。
- **背骨B(ドメイン)**: 人間の定石はAI操縦では移植不能になる(ドスク/Cinderace/マリガン3例)
  → 人間既知のコンボでも素朴パイロットは実行できない — 行動プローブで診断し規則で回復する
  (Ignition貼り先=EXP8。**コンボ自体は人間メタ既知=「AI固有の発見」と書かない**、D46)
  → ACE SPECトレードオフ(E1/E2)=「存在→発生→純効果」の3段どこでも介入は死ぬ
  → デッキはパイロットとセットでしか測れない。
- 審査員にはゲームドメインの読者を想定(3/5がポケモン社)。**Aだけだと汎用ML再現性エッセイに
  読める**。BにはAの数値が担保を与え、AにはBが具体性を与える — 節ごとに両方の弾を置く。
