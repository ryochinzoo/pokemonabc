### 3.4 リプレイは1本 7〜24MB。全パースは実行不能

12体分の全譜を落としたら **12GB** になり、`json.loads` で全部読もうとして数分で行き詰まった。

**先頭3MBだけ部分デコードすればよい**(`ladder_scout.py` の `decks_from_text`)。

さらに2つ:
- **`json.JSONDecoder().raw_decode(s, i)` は先頭の空白を飛ばさない。** `steps[0]` の後の `, ` で必ず落ちる。自前でスキップが要る。
- **`Range` ヘッダはサーバが無視して全量を返す**(2026-08-03 実測)。帯域は節約できない。ストリームを途中で打ち切るしかない。

### 3.5 Kaggle の URL とアクセス手段

- **Sim部門の正しいスラッグは `pokemon-tcg-ai-battle`。`pokemon-tcg-ai-battle-challenge` は存在しない**(404)。
  Strategy部門は `pokemon-tcg-ai-battle-challenge-strategy`。**この非対称は罠**。
- **`WebFetch` と `curl` は Kaggle の本文を取れない**(SPAでタイトルしか返らない)。
  **ブラウザツール(claude-in-chrome)が要る**。`navigate` → `wait 3-4秒` → `get_page_text` の順。
  待たないと `No text content found` になる。
- **`ListEpisodes` はログイン不要の公開POST**:
  ```bash
  curl -s -X POST "https://www.kaggle.com/api/i/competitions.EpisodeService/ListEpisodes" \
    -H "Content-Type: application/json" -d '{"submissionId": 55169074}'
  ```
  **任意のチームの submissionId で叩ける**。返り値に `initialScore` / `updatedScore` / `reward` が付く。
- リプレイ本体も公開: `https://www.kaggle.com/competitions/episodes/{id}/replay.json`

### 3.6 ハーネス側

- **Bash ツールのタイムアウト上限は 10分**。200戦×4腕のような掃引は `nohup ... &` で背面に出す。
- `sleep N` の後にコマンドを繋ぐとブロックされる。`until <条件>; do sleep 5; done` を
