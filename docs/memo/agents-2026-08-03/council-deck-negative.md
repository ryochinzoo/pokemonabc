## 1. 攻撃①: サンクコスト/物語バイアス

### 主張

「前向き検証の鎖が既にある」は論点先取である。**鎖が長いことは、鎖が正しい方向を向いていることの証拠ではない。**
ゼロベースならこのデッキを選ばない。

### 検証したこと

「サンクコスト」という単純な形では**成立しない**。チームはむしろ捨てるのが速い:
grimmsnarl(23pt外れ)を即座に最下位に落とし、crustle を vs random 78.3% で失格にし、
honchkrow を vs random 52.5% で即日中止し、壁テック案を採掘結果で自ら棄却し、
「Mirror 0-2」の誤ラベルを自分で訂正している。**投資への執着は観測されない。**

**しかし、より悪い形が観測される。「選択肢を生成していない」。**

`replay_analysis/extract_meta_decks.py` が 8/3 に抽出した実ラダー最頻出デッキは **11本、全て engine-legal**
(data.md:4056)。ディスク上に実在する(`verification/decks/meta_*_800_2026-08-03.csv`):

```
meta_alakazam_800 / meta_archaludon_800 / meta_crustle_800 / meta_dragapult_800 /
meta_dudunsparce_800 / meta_garchomp_800 / meta_grimmsnarl_800 / meta_Kangaskhan_800 /
meta_lucario_800 / meta_starmie_800 / meta_tarountula_800
```

このうち**掃引したのは crustle / garchomp / grimmsnarl / tarountula / starmie(対照)の5本だけ**。
tarountula は **1回目のスクリーニングで首位を取った瞬間から一度も競争にさらされていない。**

これはサンクコストではない。**探索の早期打ち切り(premature convergence)**であり、
バイアスとしてはサンクコストより検出が難しく、害が大きい。
チームの playbook が対策しているのは「捨てられない」病であって、「そもそも生まれなかった」病ではない。

### 判定: **部分的に命中(攻撃の形を修正して成立)**

「前向き検証の鎖」は本物だが、**鎖の起点が任意である**。
起点(5本のスクリーニング)がなぜ5本なのかに根拠がない以上、「検証を重ねた」は「正しい対象を検証した」を含意しない。

### この攻撃が当たっているなら何が観測されるはずか

- **A-1**: 未掃引6本のいずれかを同一条件(main.py md5 725ef4c9 固定・vs random N=120 → 4ゲージ N=200)で
  走らせると、**4面加重で tarountula 64.8% に匹敵または超える腕が最低1本出る**。
  特に危険なのは **meta_lucario_800**(較正ゲージ上、我々を最も強く罰する構造を我々が持つ側になる)と
  **meta_archaludon_800**(crustle 腕で 75.0% を出した対面構造の本体)。
- **A-2**: 逆に6本全てが tarountula に届かなければ、この攻撃は外れ、tarountula の選好は
  「探索不足」ではなく「実際に強い」に格上げされる。**この検査の費用は対戦のみで、コード変更ゼロ。**
- **A-3**: 反証の非対称性に注意 — 6本のうち1本でも超えたら攻撃①③④が同時に成立し、
  6本全滅なら攻撃①③は同時に死ぬ。**1回の掃引で3本の攻撃を決着できる**ので、これが最優先。

## 2. 攻撃②: レートの現実

### 主張

平衡 ~670 は王者 783/793.9 より 113pt 低い。それは Model 70% の Sim 順位項目での失点であり、
「記事の質で取り返す」は測定不能な希望である。

### 検証したこと

**(a) まず、チームが引いている「~670」という数字自体が不安定である。**

| 出典 | 日付 | P9 のスコア |
|---|---|---|
| data.md P9検死 | 8/5 | **637.7**(「検死時点、未確定」と自記) |
| claims-reverify #6 の参考行 | 8/5 | **709.3** |
| team-report §5 | 8/5 | 「**~640-700**(実測)」 |

**同じ日の2つの一次観測が 637.7 と 709.3 で 71.6pt ずれている。**
それでいて team-report §5 は「レートの落ち着き先」という**確定形の列名**でこれを掲示している。
D56 の「12時間で判断しない」規律の精神(=平衡は時間がかかる)に照らせば、
**提出+24h〜48h の値を「落ち着き先」と呼ぶのは規律違反**である。
さらに team-report §2.4 自身が「**同じエージェントでもスコアは±150〜400ぶれる**」と書いている。
その一文を採用するなら、670 と 783 の差 113pt は**自分たちの宣言したノイズ幅の内側**であり、
攻撃②もチームの主張も両方が測定不能になる。**どちらの立場も、この一文と両立しない。**

**(b) 差が本物だとした場合の大きさ。**

公開LBの2点アンカー(claims-reverify #1 実物: 596.0→3646位 / 750.0→1499位、母数6,307)から線形内挿:

| スコア | 推定順位(6,307中) | 推定パーセンタイル |
|---|---|---|
| 637.7 | ~3,065位 | 51% |
| 670 | ~2,614位 | 59% |
| **709.3(P9現在値)** | **~2,066位** | **67%** |
| 783.0 | ~1,039位 | 84% |
| 793.9 | ~887位 | 86% |

**注: 帯上部は密度が薄くなるので 783/794 の順位は過大評価(実際はもっと下位)。線形外挿の限界を明記する。**

→ **順位差は概ね 1,000〜1,700位ぶん、パーセンタイルで17〜27pt。**
Sim順位が Model 70% の5項目の1つ(≈14%)で、かつ順位がパーセンタイルで採点されると仮定すると、
**総合スコアへの影響は約 2.4〜3.8pt(100点満点)**。

**(c) 「記事の質で取り返せるか」。**

答えは**測定不能**であり、それが問題の核心ではない。真の問題は:

> **この 3.8pt の失点は、攻撃⑤が通ると「払う必要がなかった代金」になる。**

記事の材料と最終提出のデッキが分離可能なら、この失点はそもそも発生しない。
つまり攻撃②は単独では致命傷ではないが、**攻撃⑤と合わさると「無償で払った損」になる**。

**(d) さらに悪い読み方 — 平衡ではEVは意味を持たない。**

team-report §5 の表は「4面加重EV」と「レートの落ち着き先」を横に並べ、EV列を先に置いている。
これは**カテゴリエラー**である。Eloの平衡では、定義上どのエージェントも勝率50%になる。
64.8% という数字が意味を持つのは「800-1099帯の遭遇構成に置かれたら」という条件下だけであり、
**tarountula はその帯に居られない**ことを同じページが認めている。
条件が成立しない条件付き期待値を、条件が成立している他デッキの数字と並べて比較してはいけない。

実際、**P9 が実際に遭遇した構成**は前提と大きく違う:

| 対面 | 800-1099帯の想定シェア | P9 が実際に遭遇した比率 |
|---|---|---|
| Alakazam | 29.2% | **22.6%**(12/53) |
| **Lucario** | 13.2% | **24.5%**(13/53) |

**最悪対面の遭遇率が想定の1.9倍**。これは偶然ではなく、平衡が最悪対面の帯へ引きずられる構造の直接の帰結。
そして**実際の遭遇構成での実測は 26勝27敗 = 49.1% [36.1, 62.1]**。
64.8% はこのCIの中に辛うじて入るが、**点推定は50%であり、無情報と区別できない。**

### 判定: **命中、ただし有界**

- 「670 vs 783 は Sim で確かに失点」は**成立**(約1,000〜1,700位、総合2.4〜3.8pt)。
- 「記事で取り返せるか」は**判定不能**、そして攻撃⑤が通れば**問う必要がなくなる**。
- **付随して、チームの数字の提示に2つの欠陥を摘出した**: ①未収束のスコアを「落ち着き先」と確定形で提示
  ②平衡での比較に条件付きEVを併記(カテゴリエラー)。**両方とも記事に載る直前の形である。**

### この攻撃が当たっているなら何が観測されるはずか

- **B-1**: P9(55236642)のスコアを**今日と3日後に再取得**すると、637.7→709.3 の上昇傾向が続くか、
  700台で振動する。**「~640-700」という記載が実物と合わない**ことが1リクエストで確認できる。
  もし 750+ まで上がるなら攻撃②の前提(113pt差)自体が縮み、王者との差は40pt級=順位500位級に落ちる。
- **B-2**: LB CSV(1リクエスト)で 783.0 / 793.9 / 709.3 の**実順位**を引くと、上表の線形内挿は
  帯上部で外れる(実順位は推定より下位)はず。**外れ方が小さければ攻撃②は強まり、大きければ弱まる。**
- **B-3**: team-report §2.4 の「±150〜400ぶれる」の出所を辿ると、王者系列3回の実測レンジ 747-794(幅47)
  と矛盾するはず。**どちらかが誤り**。記事に両方は書けない。

## 3. 攻撃③: メガルカリオ未測定の穴 — **最も深く刺さった攻撃(その1)**

### 主張

「測ったなかで最良」を「最良」と言い換えている。

### 検証したこと

**言い換えている。しかも、測らなかった理由が存在しない。**

我々の操縦者(main.py md5 725ef4c9)を載せて掃引したデッキの全数:

| デッキ | vs random | 4ゲージ掃引 | 本番プローブ |
|---|---|---|---|
| tarountula | 98.3 / 99.2% | 済(4面) | 済(P9) |
| crustle | 78.3→82.5%(失格) | 済(4面) | — |
| grimmsnarl | 95.8%(境界) | 済(4面、修理版も) | — |
| garchomp | 100.0% | **Alakazam 1面のみ(51.5%)** | — |
| honchkrow | 52.5%(即死) | 中止 | — |
| starmie(対照) | — | 済 | 済 |

**一度も走らせていないデッキ(deck.csv はディスク上に8/3から存在):**

| デッキ | 帯シェア | なぜ測るべきか |
|---|---|---|
| **meta_alakazam_800** | **29.2%(最大)** | フィールド最大勢力。EV表 46.9。**我々の主砲は「アラカザムを狩る」なのに、アラカザムを持ったことがない** |
| **meta_lucario_800** | **13.2%** | **tarountula を 14.0%/15.4% で轢いた当のデッキ**。相手として最強なら、こちらが持ったら? |
| **meta_archaludon_800** | **10.7%** | tarountula の唯一の構造的自動負け(9.0%)。crustle 腕はこの対面で 75.0% を出しており、対面構造は操縦者と噛む |
| meta_dragapult_800 | 2.1% | 尾部 |
| meta_dudunsparce_800 | — | 尾部(公開実装が現存する唯一の系統) |
| meta_Kangaskhan_800 | — | 尾部 |

**費用**: vs random N=120 のゲートは crustle/garchomp/tarountula/grimmsnarl で実績があり、
1本あたり数分規模。4ゲージ掃引は各N=200×4面。**コード変更ゼロ、事前登録の様式も既にある。**
つまり**やらなかったことに技術的理由も資源的理由もない**。

さらに悪いことに、`extract_meta_decks.py` は red-team-D §8.2 で
「提出数<8のアーキタイプと other を**無言スキップ**」と指摘されている。
**候補生成器そのものが黙って候補を落としている計器**であり、
「11本」という母集団自体が上界ではなく既に切り詰められた集合である。

### 判定: **決定的命中**

現在の主張の正確な形は:

> 「**実ラダー最頻出11本のうち、我々が選んだ4本+人間輸入1本の中で、tarountula が最良だった**」

「最良」を名乗るには、最低でも**最大勢力(アラカザム 29.2%)と我々を殺す2本(ルカリオ・ブリジュラス)**を
同一手順に通す必要がある。それを通していない状態で最終提出と記事の主役に据えるのは、
**チーム自身が D63 で立てた「根拠は『上位が使っているから』ではなく実測で」という規則の、実測側が薄い版**である。

### この攻撃が当たっているなら何が観測されるはずか

- **C-1**: 未掃引6本の vs random ゲート(各N=120)を走らせると、**3本以上が96%フロアを通過する**
  (crustle/honchkrow のような即死は少数派のはず。garchomp 100%・tarountula 98.3% が先例)。
  通過が0〜1本なら、この攻撃は大幅に弱まり「実質的に候補は無かった」が成立する。
- **C-2**: 通過した腕を4ゲージ掃引すると、**Lucario列で 14.0%(tarountula)を大きく上回る腕が出る**。
  ルカリオ帯が平衡を決める以上、Lucario列の値が最終順位に最も効く。
  **meta_lucario_800 のミラーが 50% 近辺に落ち着けば、それだけで tarountula の 14.0% より平衡は上がる。**
- **C-3**: 逆に、tarountula が6本すべてに4面加重で勝ち続ければ、**攻撃①③は同時に死に、
  「最良」という言い方が初めて正当化される**。私はこの結果を歓迎する。それが本来やるべき実験だからだ。

## 4. 攻撃④: v2の楽観 — **最も深く刺さった攻撃(その2)**

### 主張

ミュウツー削減・ハイパーボール追加が効く保証はない。効かなかった場合の撤退基準は?

### 検証したこと

**撤退基準は、どの文書にも1行も書かれていない。**

team-share §4 の「進め方」は
「Aの各要素を個別に較正ゲージでスクリーニング → **通った束だけで**プローブ → その実測で凍結設計」。
これは前進の手順であって、**「全部落ちたらどうするか」「どこまで落ちたら王者に戻るか」を含まない**。
チームは P9 の事前登録では中止条件を4つ書けている(CRASH/不正手、エピソード消費>60秒 等)。
**同じ人たちが、より大きな決定(最終提出の主役)については中止条件を書いていない。**
これは能力の問題ではなく、**その決定が既に既定路線として扱われている**ことの症状である。

**さらに、v2の4要素を個別に潰す。**

| v2要素 | 実測根拠 | 私の反論 | 期待効果の上界 |
|---|---|---|---|
