## 1. アーキタイプ評価 — ロケットラッシュ体系の筋

### 1.1 機構の正体: 30×N は「火力」ではなく「盤面の三重計上」

ロケットラッシュ(ワナイダー、[草][無]で 30×自分の場のTRポケモン数)は、盤面の数を
**火力・耐久・サイドレース**の三つに同時計上する構造になっている。

- 火力: 盤面6で180、盤面4で120、盤面3で90。
- 耐久: 盤面が広い=1体KOされても総打点の減りが相対的に小さい。
- サイド: 全員が非exなら相手は6回KOしないと勝てない。

**エネルギーがたった2個で最大180**という点は率直に強い。しかもロケット団エネルギー(超悪2個ぶん)は
[草]を払えないので**必要なのは基本草1枚+何でも1枚**——つまりチャージアップ(トラッシュから基本エネを
自分に付ける)と合わせて、**主砲が2ターン目に立つ設計**になっている。ここまでは良いデッキだ。

### 1.2 構造的限界①: 負のフィードバック(逆転できない)

30×N は**こちらが負けている間だけ小さくなる**。1体倒されるごとに打点が30落ちる。
相手はKOするたび強くなり、こちらはKOされるたび弱くなる。紙の競技で「場の数×」系の攻撃が
トップメタになりにくい最大の理由がこれで、**先に殴られると加速度的に詰む**。

P9実測がそのまま出ている: Lucario敗戦11本での我々の攻撃回数は**中央値2回(相手6回)**、
獲得サイド0〜1枚の完封級が**8/11**。これは操縦の下手さではなく、**アーキタイプの折れ方そのもの**。

### 1.3 構造的限界②: 天井180 vs 場のHP分布 — かつ**全員が130の一撃圏**

| 相手の主砲 | HP | ロケットラッシュ180で | 相手の一撃打点 | こちらで耐える体 |
|---|---|---|---|---|
| フーディン 743 | 140 | **1発**(盤面5でも150で足りる) | ダメカン(効果) | Veilで無効 |
| ブリジュラスex | **300** | 2発(フルメタルラボ−30込みで盤面6が必須) | メタルディフェンダー**220** | **なし** |
| メガルカリオex | **340** | 2発 | オーラジャブ**130** / メガブレイブ270 | **なし**(マント込みのワナイダー230のみ) |
| オーロンゲex | 320 | **1発**(草弱点×2、§1.5) | シャドーバレット180+30 | なし |
| メガスターミーex | 330 | 2発 | ジェットブロー120+50 | ワナイダー130が耐える |

**要点は2行**:
- 我々の主砲は**300HP級に2発必要**。相手は**1発**。
- **オーラジャブ130(1エネ、しかもトラッシュから闘エネ3枚をベンチに配給)が、我々の全ポケモンを一撃で落とす。**
  ヒーローマント(+100)を貼ったワナイダー230だけが例外で、それはACE SPECなので1枚しか入らない。

**この2行が Lucario 14.0%(較正ゲージ N=200)/ Archaludon 9.0% の全部**であり、
たね増量でもボール追加でもミュウツー削減でも動かない。**動かせるのは打点の天井を上げるか、
HPの下限を上げるかだけで、TRのカードプール全98枚を1枚ずつ見た限り、その両方を満たす札は無い**
(§3.3で候補を全部潰した)。

### 1.4 なぜフーディンにだけ勝てるのか — Veilの射程と、デッキ設計の自己矛盾

レジストヴェール(フリーザー): 「このポケモンがいるかぎり、自分の場の**【たね】**ポケモンの
ロケット団全員は、相手のポケモンが使う**ワザの効果**を受けない」。

- **たね限定**。だから**主砲のワナイダーは1進化=保護対象外**。
- **ワザの効果限定**。だからマシマシラ(特性)のダメカン移動は素通り(P9でターンレベル確認済み)。

P9の534ダメカンの内訳(**Spidops 480(89.9%)/ たねTR 54(全てフリーザー不在ターン)**)は、
「**このデッキは自分の主砲を守れていない**」という設計上の矛盾を数字で示している。
**Veilが全開になるのは、攻撃役がたねのときだけ**。これは記事に書ける一級の観察であり、
同時に「Veil軸をもっと押す」方向の改良が**主砲を替えない限り不可能**であることの証明でもある。

そして肝心のフーディン対面で勝てるのは、**相手の打点が全部「効果」だから**であって、
Veilが強いからではない。**フーディンは対戦相手として例外的にVeilと相性が悪いだけの1アーキタイプ**。
言い換えると: **タマンチュラは場のデッキではなく、メタコール(1対面への刺し札)である。**

### 1.5 見落とされている最大の上振れ: オーロンゲ系は**ライン全員が草弱点**

これはチームの資料のどこにも書かれていない。

| オーロンゲ側 | HP | 弱点 | ロケットラッシュ(ワナイダー=【草】)で必要な盤面 |
|---|---|---|---|
| マリィのベロバー | 70 | **草** | 盤面2(60→120) |
| マリィのギモー | 100 | **草** | 盤面2(60→120) |
| **マリィのオーロンゲex** | **320** | **草** | **盤面6(180→360)= 1発で2サイド** |
| マシマシラ | 110 | 悪 | 盤面4(120) |

**盤面6のロケットラッシュは、場の19.3%を占める第2勢力の主砲を一撃で落とす。**
盤面5だと 150×2=300 で20足りない。**6体目の盤面が、そのまま2サイドのKOに化ける。**
P9の Grimmsnarl 3-2(5 distinct)は「純粋なサイドレース」と記録されているが、
**本来は弱点対面**であり、負けた2本は盤面が細った試合(記録に「盤面最大2の立ち上がり事故」1本)。

→ **v2で最も投資すべきは「盤面幅」であり、その最良の札はハイパーボールではなくなかよしポフィン**(§3.2)。

### 1.6 我々のパイロットと噛み合う本当の理由(D64の精密化)

data.md の D64 は「動力源が常在効果か能動選択か」で説明しているが、**カード実物を見ると理由はもっと狭い**。

このデッキで **ABILITY(明示的に押す行動)として提示されるのはチャージアップ1種類だけ**。
レジストヴェールもパワーセーバーも常在(=SKILL、選択肢に出ない)。
つまり `main.py:335` の「最初のABILITYを中身を見ずに押す」は、**このデッキでは常に正解**。

> **不変条件(どこにも記録されていない): タマンチュラの94.5%は「押せる特性が1個で、それが常に正解」に依存している。**
> v2で活性特性持ちを1枚でも足すと(例: ロケット団のゴルバット/クロバットex/イオルブ/ポリゴンZ)、
> 盲打ちの当たり判定が壊れる。**ポリゴンZ(手札2枚トラッシュで1ドロー)は crustle と同じ自滅機関**。

裏返した設計原理がこれ:

> **パイロットを教育するのではなく、デッキ側で選択の余地を消す。**
> 「超エネの74%が型不一致先に貼られる」という穴は、**基本超エネを0枚にすれば消滅する**(§3.2で成立を確認)。

これは記事の主張として、パイロット修理の話より強い。**deckcrafting の定義そのものを「AIの認知に合わせた構築」に読み替える**論点で、
運営が名指しした評価軸に真正面から答える。

### 2.1 表から読める一番大事なこと

**現王者(メガスターミー)とメガルカリオは、カードとしてほぼ同じ形をしている。**

| | メガスターミーex | メガルカリオex |
|---|---|---|
| 形 | 1進化・メガex | 1進化・メガex |
| HP | 330 | **340** |
| 主砲 | ジェットブロー[水]120(+ベンチ50) | **オーラジャブ[闘]130 + トラッシュから闘エネ3枚をベンチに配給** |
| 決め技 | ネビュラビーム[無無無]210 | **メガブレイブ[闘闘]270** |
| 特性 | なし | **なし** |
| エネ | 基本水11+特殊4 | **基本闘14(単一)** |

**我々のパイロットは7ヶ月「1進化メガex・特性なし・damage欄に打点・低エネ始動」という形だけを見て調整されてきた。
メガルカリオはその形の上位互換に見える**(HP+10、打点+10、しかも**攻撃しながら次のアタッカー2〜3体を自動装填**、
決め技が270、そして**エネが単一種なので我々の最大の実測バグ「型盲目エネ配分」が発火しようがない**)。

紙の目で見て、オーラジャブは**このカードプールで最も効率の良い攻撃**だ。1エネで130を出しながら
トラッシュの闘エネ3枚をベンチに配る——「殴りながら次の2体を立てる」札は、紙の競技なら初見で
デッキの軸に据える強さがある。ラダーのメガルカリオ勢が場の13.2%(600-899帯では16〜19%)を占め、
我々を **2勝11敗(13 distinct)/ 較正ゲージ14.0%(N=200)** で轢いているのは、偶然ではない。

### 2.2 ★「メガルカリオを自分で使う」が検討から漏れているのは穴か → **穴である**

**事実確認**: deckswap の腕として測られたのは tarountula / crustle / starmie / grimmsnarl(±fix) /
garchomp / honchkrow の6本。**lucario・alakazam・archaludon は一度も我々の腕になっていない。**
これは場のシェアで **13.2 + 29.2 + 10.7 = 53.1%** に相当する。

**なぜ穴だと言い切れるか(3点)**

1. **チーム自身の互換性規則が、メガルカリオに満点を予測する。**
   D64の可否リスト「damage欄(可)/常在特性(可)/効果由来の配分(修理可)/自己消費機関(不可)/テキスト内打点(完全盲点)」
   に対し、メガルカリオは **damage欄 ◎ / 活性特性0 / 自己消費なし / テキスト打点なし**。
   唯一の懸念(オーラジャブのトラッシュ→ベンチ配分)は **ctx=21 ATTACH_FROM** そのもので、
   **abilityfix束が4アンカー全部で有意に直したと実測されている文脈**(+20.0/+13.0/+13.5/+5.5pt)。
   **理論が最も強く推薦するデッキだけが試されていない。**
2. **「使わない根拠」として使えそうな数字が、全部チーム自身の規則で無効化されている。**
   - フィールドEV lucario 46.5% → これは**他人の操縦者込みの deck×pilot**。
     H1(実ラダー順位の転移)は**4アンカーで連続棄却**、しかも**±42ptの両方向に外れる**と実測済み。
     この数字で候補を落とすのは、チームが4回禁じた単位混同そのもの。
   - 帯別センサスの lucario セル → 監査で「**5〜11体に乗っている=パイロットの話。デッキの主張に使えない**」と
     自分たちで赤字にしている。
   - **つまり現時点で「メガルカリオは我々に向かない」と言える証拠は1つも無い。無いのは測定だけ。**
3. **測定コストがゼロに近い。デッキは8/3にもう抽出されていた。**
   `verification/decks/meta_lucario_800_2026-08-03.csv` は **デッキ入替スクリーニングと同じ日に作られ、
   そのまま一度も腕にならなかった**(`meta_archaludon_800_...` `meta_alakazam_800_...` も同様。
   `src/input/datasets/decks/` に deckswap-lucario は存在しない)。
   `main.py` は変更不要、較正ゲージ4本は既存。**ディレクトリを1つ複製して deck.csv を差し替えるだけ**で、
   vs random 120 + 4ゲージ×200 = 既存の掃引と同じ手順1回。凍結(8/13-16)まで一週間ある。
   **やらない理由が見当たらない。**

**私の事前予測(反証可能な形で登録することを推奨)**:
`deckswap-lucario`(操縦者=王者 725ef4c9、デッキのみ差替)の
**4面加重(Alakazam29.2/Lucario13.2/Archaludon10.7/Crustle13.5 再正規化)= 55〜70%**、
**現王者の52.1%を上回る**。とくに **vs Alakazam ≥55%**(オーラジャブ130がフーディン140をほぼ一撃、
ダメカン打点は340HPに対して遅い)と **vs random ≥97%**(単一エネ・特性なし=事故要因が最小)を予測する。
**外れる場合の最有力機構は「ミラー(場の13.2%)で先に殴られる側になる」と「メガex=3サイドの負債を
パイロットが無視する」**。この2つが効くなら4面加重は50%を切る。

**なぜ漏れたのかの推定(遠慮なく書く)**: (a) Lucarioは「敵」として測られ、候補として測られなかった。
(b) 機構仮説(常在動力)が tarountula / honchkrow を指したので探索がその筋に沿った。
(c) **P9提出後のサンクコスト**。53戦の解剖という大きな投資の後で、別デッキの掃引は「後戻り」に見える。
(a)(b)は健全な探索の副作用だが、**(c)は今まさに判断を歪めている**。

### 2.3 その他の対抗馬に一行ずつ

- **フーディン**: 最大勢力(29.2%)だが**ハンドパワーがdamage欄n/a=honchkrowの死に方をなぞる**。却下。測るまでもない。
