# 作戦: 本番プローブ・キャンペーン (2026-08-01起案、ゆうじ承認待ち)

**方針(ゆうじ 2026-08-01)**: 期間を言い訳にしない。捨てたやり方も拾って本番で試す。
本番を第一級の計器に格上げする。

**再定義(重要)**: 本番は勝率の相対差(±2-4pt)を裁けない(ablation-validity.md: ±19pt/提出)。
よって「拾う」= 棄却変種を**①計器較正の錘(異なる予測水準の絶対アンカー) ②挙動 in-the-wild
のデータ源**として使う。**killの再審はしない** — 再審はプローブが新証拠を出した場合のみ
(playbook既存規則)。狙う成果物: **較正曲線 n=4→n=10+、予測水準の幅31.8〜45.1pt**
(現行アンカーは35-44に密集)+挙動・タイミングの本番実測群。writeup主砲#3の格上げ。

## kill再審の禁止(レビュー修正3、一字不変で固定)

プローブの本番実測は、いかなる値であっても kill の再審理由にならない。
再審の条件は playbook 既存規則（新証拠）のみで、
「予測より良かった」は新証拠に当たらない（N≈20・±19ptの分解能以下）。
プローブ結果を根拠に採択・再審を提案した時点で、その提案は無効とする。

(適用範囲の注記: 上記は**採択・再審の提案**を禁じる。挙動系エンドポイント
(同定率・発火率等)を観測として台帳・writeupに記録すること自体は提案ではなく、禁止の対象外。)

## 中止条件(レビュー修正4、事前固定)

1. **CRASH≥1 または 不正手/INVALID≥1 → 全プローブ即時停止**。原因特定+robustness再監査まで再開しない。
2. Kaggle提出エラー(パッケージ不備等)≥1 → 停止、診断後に再開(スロット浪費防止)。
3. **T1粗外れ(実測が事前CI外)が2本連続 → キャンペーン一時停止**、T3/計器監査を先行。
4. 検死でエピソード時間消費>60秒(バンクの10%)を観測 → タイミング系プローブ(幅・v3)停止、射影再構築。
5. 穴D規則2発火 → 列組替(B較正プローブを優先挿入)。
6. 8/11時点で未消化のプローブは切り捨て(最終締めバッファ優先)。
