# ゆうじのカードパターン集 (2026-08-16 夜) — 9月実装候補 + レポート素材

発案: ゆうじ(8/16のロジック議論)。検死データとの突合はcc。**凍結中につき実装は9月以降。**

## パターン(いずれも現行パイロットに無い、または不完全)

1. **進化前狙撃→ボス引き出し→170キル**: 相手ベンチの進化前(例: リオル HP70-80)に
   ジェットブローの50を「前払い」→ 次番ボスの指令で引きずり出して120(計170)。
   **進化ラインを完成前に折る**。ルカリオ対面(実測40%=最弱セル)への直接の解答候補。
2. **ジェットブロー/ネビュラの使い分け価値関数**: 残りサイドと相手盤面から
   「210で1枚」vs「120+50で複数枚ライン(ダブルKO含む)」を分岐。
   ベンチ50は**弱点抵抗を計算しない=確定50**(カードテキスト確認済み)。
3. **ボスの指令の攻め手用法**: 天敵をどかすだけでなく「中途半端HP(130等)を前に出させて
   にげエネを強要+滞留中にベンチへ50蓄積」— 遅延と削りの二重価値。
   ※検死の実例: ep92473413 決定38-40 でボスを1枚獲物(Morgrem)に使い、
   目前の2枚獲物(HP110のGrimmsnarl ex)を放置した誤爆あり = 価値関数不在の証拠。
4. **犠牲管理**: メガex(3枚献上)を2枚取られた時点で実質敗勢 → ヒトデマン(1枚)を
   意図的に餌にしてベンチでメガを再構築。勝ち譜ep92586696の「終盤にベンチへ軽い餌を
   置かない」と対になる**サイドレース設計**。現行は _prize_value(KOCAP)で部分的にのみ考慮。
5. **メタ観測→先回り狙撃**: 相手デッキをメタ辞書で同定できるなら「この後脅威になるたね」を
   事前に狙える(現行の辞書は探索の決定化にしか使っていない)。

## レポートへの反映(重要)

ボス実験(#34)の主張は**最初から pilot-scoped**(台帳の指示): 「ボスの指令が弱い」ではなく
「**我々のパイロットにはボスを活かす価値関数が無く、その状態での+1枚は−1.53ptだった**」。
ゆうじの批判はこの限定の正しさの再導出であり、テーゼ「カードの価値はデッキ×パイロットの積」の
機構説明(なぜ弱かったか=誤爆の実物+欠けたパターンの特定)として§4に織り込む。
ルカリオ40%の弱点も同型: 「負ける理由を検死し、欠けたパターン(進化前狙撃)まで特定した」
と書けば、弱点の開示が理解の証明に変わる(審査基準④への強い答え)。

## 訂正1件(ゆうじの前提)

「このエンジンはマリガンで相手の手札が増えない」は**誤り** — エンジンソース(SetupProc.h)で
**相手が0..N枚の追加ドローを得る実装を確認済み**(台帳L-c、writeup本文も一度この誤りを踏んで
訂正した)。それでも「たね4枚(マリガン60%)が8枚・10枚より強い」が実測 — ペナルティの実コストが
デッキ枠の死に札コストを下回る、という発見の面白さはむしろ増す。
