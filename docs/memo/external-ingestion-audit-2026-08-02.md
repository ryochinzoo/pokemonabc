### 8.2 API上の落とし穴(ホスト回答つき)

- **ABILITY と SKILL の別**: ABILITY=明示的に選択する行動 / SKILL=受動・継続効果。
  クレフェアリー型の常在効果は**自動適用**で、毎ターン選ぶ必要はない(ホスト shige が承認)
- **セットアップのベンチ展開**: `context == SETUP_BENCH_POKEMON` かつ `minCount == 0` なら
  **空リスト `[]` を返してスキップできる**。END オプションが無いのは仕様
- **ベンチに下げると効果が「掃除」される**: Mega Lucario ex の Mega Brave 制限は、
  リトリートしてベンチ経由で戻せばリセットされる
- **Mega Lopunny ex の Gale Thrust はシミュレータが正しい**(進化すると「ベンチから動いた」が
  リセットされる、とホストが裁定)
