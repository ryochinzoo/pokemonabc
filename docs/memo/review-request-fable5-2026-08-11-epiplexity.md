## 4. 論文の中身(起案者の読解。ここが違っていたら真っ先に指摘してください)

**「確実性の論文」ではない。「計算に縛られた観測者にとって何が情報か」の論文。**

中心概念は情報の二分割:

| | 中身 |
|---|---|
| **エピプレキシティ S_T** | 有界計算で抽出できる**構造**。モデル自体を記述するのに要するビット |
| **時間制限エントロピー H_T** | どれだけ計算しても縮まない**見かけの乱雑さ** |

- 核となる主張: *"information is observer dependent: the same object may appear random or
  structured depending on computational resources."*
- 決定的変換が情報を生む理由(§5.1 の逆説の解決): 逆変換に効率的な実装が無いから。
  *"With limited computation, a description of the AlphaZero algorithm and the result of
  running AlphaZero for thousands of TPU hours are distinct."*
- 例示: セルオートマトン **rule 30**(高 H_T / 低 S_T = 誰も何も学べない)vs
  **rule 54**(高 S_T = 学べる構造がある)。**同じ決定的CA族なのに片方は学習不能。**
- 計測法(§4.1): **prequential coding** = 「**学習曲線の、最終損失より上の面積**」= S_T の推定値
- 著者自身が置いた限界:
  - *"epiplexity is a measure of information, **not** a guarantee of OOD generalization
    to specific tasks."*
  - 唯一の形式的下界 Theorem 10(一方向性関数を仮定して epiplexity Ω(log n))について、
    *"still far from the power law scaling we see with some natural data"*
  - 枠組みは**X の完全観測を前提**。隠れ情報 / 部分観測 / ゲーム理論は扱っていない

### 主張B: 公開性のパラドクス
