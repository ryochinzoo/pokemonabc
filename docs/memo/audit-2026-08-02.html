02計器の故障 — 自作ゲージ2つと、CEWの重み

自作ゲージは2つとも、実在する相手と半分も一致していなかった

ゲージ実ラダーとの加重一致実ラダー遭遇影響
alakazam_v0.csv24.7 / 6052戦計器は「96%勝つ」と表示。実ラダーは 51.7%
grimmsnarl_v0.csv27.4 / 6022戦同型。D61の処置対象を拡張

ただしデッキ抽出は我々が正しかった。 meta_alakazam_2026-07-14.csv は 最頻出の実物と 60/60 完全一致、加重 55.5/60 で公開版(50.8 / 51.6)より実ラダーに近い。 誤りは「正しいデッキを持ちながら、ゲージがそれを使っていなかった」という接続の欠落。

三段分解(N=300/腕): 自作P×自作D 96.0% → 自作P×実物D 89.0% → 本物P×実物D 57.3% → 実ラダー 51.7%。 デッキ差 7.0pt / 操縦者差 31.7pt(操縦者が4.5倍効く)。 新ゲージと実ラダーの差は 5.6pt で実ラダーCI内 = 較正できている。

CEWの重みは、外部データに棄却された

良い知らせ2つ
  • 我々の「遭遇1位 Alakazam 30.9%(n=55)」は外部で追認された(26.21%、n=290)
  • カバレッジ 46.2% → Alakazam を第5成分に足すだけで 72.4%。今日設置したゲージがそのまま効く
外部メタを使うときの罠

大規模な外部メタ(pilkwang 7万戦 / busyaprime 4千戦 / smallpond 5千戦)は 全て「Daily Top Episodes」由来 = 上位帯偏りだった。 証拠: busyaprime 7/31 の dump で Grimmsnarl 63.77%、 しかし我々の 700-799 帯では 6.90%。 使えるのは myso1987 の帯別1本だけ。

03私(cc)の誤りと、その訂正

この日の対話中に私が述べ、根拠として使われかけた誤りが3件ある。すべて記録側で訂正済み。

#誤った記述正しくは訂正先
C1 「Alakazam の練習相手がいない」 持っていた(gauges/alakazam_agent.py、7/13自作)。正しくは「持っているが自作なので採点式に使えない扱いにしている」。またこの文脈で「公開版を取ればデッキも直る」と読める説明をしたが、デッキは我々の抽出の方が正確 data.md 補遺
C2 「CEWの4成分は全部外部由来なので今の判定基準は無傷」 ゲージ(計器)は外部由来で無傷だが、重み(遭遇分布)は棄却された(χ²=37.68)。「判定基準は無傷」は言い過ぎだった data.md 補遺
C3 「純ヒューリスティックの観測上の天井はランク150前後」 2名の個別実績であって上限ではない。同じスレッドでトップ10の Cox & Chao 組がルールベースだと目されている。読み違い external-ingestion §8.3
言を翻した点(D62に明記)

セッション中盤、私は「CEW拡張は 8/17 以降にすべき(事前登録が無効化されるため)」と述べた。 その後 χ²=37.68 で重みが棄却されたため撤回した。 「変えない」ことは、棄却された計器を使い続けることであって保全ではない。

ただし事前登録の保護は有効なので、移行規則を D62 に固定した:

  • 既に事前登録済みのプローブ(P1〜P5)の判定は旧重みのまま。遡及適用しない
  • 新重みは並行して計算し、両方を記録する。8/16以降の新規登録から新重みを正典に
  • 旧重みと新重みの数値を、同じ表・同じ文の中で混ぜない

04検査して無事だったもの

他人が踏んだ罠が我々に当たっていないかを、実測で確認した。

検査結果
✓__file__ 依存(Kaggleの exec() 下では存在せず validation で ERROR) main.py は非依存。使用は公式 cg/sim.py のみで import されるため安全

06決めたこと(D62、ゆうじ承認済み)

重心を「レポート磨き」から「エージェントの穴塞ぎ」へ移す。 着手順:

#やることなぜ
1対面判定のラベルを方策に接続実装済みの情報を使っていないだけ。最も安い
2ターン内資源フラグを読む「攻撃はターンを終わらせる」から行動順序が導出できる
3CEWを直近提出のみ + Alakazam 第5成分にカバレッジ 46.2%→72.4%、χ² の非整合が解消
4探索の扱いを決める現状は偽の山札の上。上位は誰も使っていない機構に予算の83%

やめること: CEW拡張の事前登録を先頭に置く案(私が本日提案したもの)、レポートの磨き込みの優先。

これはレポートにとっても正しい選択である。 「較正済み計器で穴を見つけ、直し、前向き検証で当てた」という実際に機能した物語は、 既出の法則を語り直すより強い。

ゆうじの懸念は当たっていた

「記事から逆算する作戦が、逆に方向転換の妨げになっていないか」—— 症状が実際に出ていた。今日の44ptの発見に対し、私が最初にやったのは 「台帳#1の4点目として昇格できる」= 既存の枠への格納であり、 「この発見は背骨を変えるか」とは一度も問わなかった。
