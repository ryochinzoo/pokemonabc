§1背景 — スターミーの限界と、いまのメタ

スターミー(現王者、確定レート783/793.9)の測定された限界

  • レート700を超えた瞬間に勝率52%→41%(帯別の実測)。負け筋はブリジュラス16.7%・ミラー0勝3敗・上位のメガルカリオ。
  • 「語れる要素」が測定した全デッキ中最少 — 中身はこう(すべて実測): 特性0個・スタジアム0枚・妨害/回収/ダメージ操作カード0枚(上位勢はクラッシュハンマー、マシマシラのダメカン移動、夜のタンカ等の「個性札」を毎試合回している)。1試合に使うカード12.9枚(上位勢15〜23)/ カードの種類11(同12〜16)/ 攻撃するポケモン2種(同3〜4)/ よく使うカード上位5枚が全部汎用のサーチ・ドロー。デッキが呼び出すゲーム機構の数を数えた指標で12本中最下位(40点、中央値68)。
  • なぜ問題か: 審査のDeck 20%は「構築の判断」を見る。判断が発生する機構が少ない=記事に書ける判断が少ない。運営も「deckcrafting」を名指しで評価軸に挙げている(§2)。スターミーは「エンジンの穴を突いた合理的なデッキ」だが、記事の主役としては構造的に弱い。

メタの分析(全対戦ログをレート付きで集計=この形のデータは我々しか持っていない)

レート800-1099帯の顔ぶれ: フーディン29.2% / オーロンゲ19.3% / イワパレス13.5% / メガルカリオ13.2% / ブリジュラス10.7%。ここで重要な発見——このメタは「強さ」で並んでいない:

  • 使用率と勝率の相関はほぼゼロ(ρ=−0.02)。最多のフーディンは勝率ワースト3。
  • オーロンゲは723チーム中505チーム(69.8%)が完全に同じ60枚。公開コードは0件(公開ノートブック291件を全部実行して確認)なのに788チームいる=公開リプレイからの模倣学習で量産。8位のJakeも「データが大量にあるから作りやすい」と証言。
  • → メタは「コピーしやすさ」で決まっている。たった2種類の同一リストが全チームの35.6%。
だから何をしたかパイロット(main.py)を1バイトも変えず、deck.csvだけ差し替えて勝率を測る実験をした。デッキだけで勝率が最大60pt動いた(パイロット側を7ヶ月改良して得た最大値は+13.6pt)。デッキ選びのほうが4倍効く。記事審査もデッキ構築を要求している——デッキ転換はSimと記事の両方に効く、が転換の根拠。

§2外部調査で得た情報(すべて一次情報を実物確認済み)

2.1 審査員が見るもの

  • 配点: Model 70%(5項目あり、Sim順位はその中の1つ=全体の約14%)/ Deck 20% / Report 10%。記事は2,000語。審査員はポケモン社3名:松尾研2名。
  • 運営の明言: 「機械学習は必須ではない。ルールベース+構造化されたレポートで十分競争力がある」「思考プロセス・試行錯誤・教訓を共有してほしい」「deckcraftingが要る」。
  • 決勝8枠($30k×8、東京・対面)は記事の評価だけで選抜。決勝は3本勝負・前の試合のログ参照可・デッキとコードは予選と別でも良い。
  • 提出済みの記事289本は締切まで誰も読めない(スタッフ回答で確認)——差別化は「他人が持てない材料」でやるしかない。

2.2 コミュニティで議論されていること(→ 我々の作戦にどう効くか)

  • Discord(公式サーバ。ゆうじのログインで初めて偵察できた):
    • Jack pという参加者:「AIがルールを模倣するのに、単純なルール(例: ポケパッドがあれば必ず使う)は10試合分で真似できる。だが複雑なルール——『ロケット団のフリーザーを対フーディン戦で場に維持し続ける』ような立ち回り——は1000試合分の実例が要る」。これはまさに我々が本番で11勝1敗を出した仕組み(§7)のこと。複雑な対面テクニックはコピーされない=我々の防御壁。
    • 「ML専門家は自分が遊ばないゲームを道具で最適化しているだけ」という指摘。一部チームは「ルールベースだと審査で不利かも」と勝手に忖度して避けている(運営の明言と矛盾。我々には追い風)。
  • 思考時間の分析(掲示板、73票): 参加者の半分はルールベース。強化学習+探索は1位だけ。
  • SUMIの全数集計(74,634戦)から分かることは3つ: ①メタの時系列(どのデッキがいつ増えたか) ②「流行っても強くならない」の実証——オーロンゲは使用率17%→51%に増える間に、ミラー戦を除いた勝率が50.3%へ収束(=コピーが増えるほど旨味が消える) ③ブリジュラスは「誰も使わない時は勝率65%、流行った瞬間に48%→31%」——見えている強デッキに乗り換えた時にはもう遅い。我々が「流行デッキに乗らず実測で選ぶ」方針なのはこれが根拠。なおSUMIのデータにはレートが無いので帯別分析はできない——そこは我々のデータだけができる(記事の差別化点)。
  • Oshbocker(37位)は「リプレイから模倣されるのを防ぐためダミー提出で本命を隠す」戦略を公言。

2.3 ゲームメタの構造

  • マッチング仕様が公式開示: 4分ごと・レートが近い相手・直近2提出だけが対象。
  • 帯構造: レート600-800はメガルカリオ/ユキノオーの群れ、800-1000はフーディン/オーロンゲ中心。レートの落ち着き先は「一番苦手な相手が多い帯」で決まる(今回のプローブで実証)。
  • 人間の大会とAIラダーは別ゲーム: AI最大勢力のフーディンは人間のシティリーグ入賞16デッキに0本。

2.4 その他(議論しがいのある話)

  • 練習相手の「嘘」が見つかった: 運営配布サンプル(メガルカリオ)相手の勝率は、本物の上位プレイヤー相手より45ptも甘い(§7)。りょーちんがローカルで測るときも同じ罠があるので§9の較正済みゲージを。
  • 同じエージェントでもスコアは±150〜400ぶれる——単発のレートで判断しない。提出枠は毎日5回復・最終順位は凍結時の直近2提出だけ=枠は貴重品ではない。

§4分析の結果わかったこと(要点5つ)

  1. メタは「コピーしやすさ」のシステム。標準化された実物リストに対して実測で選ぶのが最強の選定手段。
  2. デッキとパイロットの相性は、少数の「盲点」に集約される。3系統: ①特性で得た資源の配り先を考えない(修理で+13〜20pt) ②山札を削る特性を毎ターン押して自滅 ③ダメージがテキストにしか書いていない技を0点と評価。
  3. 他人が使って強いデッキが、我々のパイロットで強いとは限らない(−23pt〜+42ptの両方向にズレた)。選定は必ず「我々のパイロットを載せた実測」で。
  4. セルフ対戦は当てにならないと分かり、測定を「外部の実物」相手に全面転換した(←重要な方法論の変化): 自分のパイロット同士の対戦で測る勝率は、本物の相手より+8〜+62pt甘く出ると実測で判明。以来、勝率の判定は全部外部の実物エージェント(他チームの公開agentを固定の練習相手にしたもの=§9)か本番ラダーで行い、セルフ対戦は下書き確認用に格下げした。§7の「フーディンに11勝1敗」も本番の他チーム実物が相手。りょーちんのローカル測定にもそのまま効く話。
  5. その練習相手にも嘘がある(運営サンプルのメガルカリオ相手は、本物の上位プレイヤー相手より+45pt甘い)。本番実測と一致する練習相手に世代交代した。

§6いま試していること — なぜタマンチュラ系を選んだか(正直な経緯)

6.1 選定の方法 — このデッキは「設計」ではなく「輸入+選抜」

我々が1枚ずつ考えて組んだデッキではない。本番ラダーのタマンチュラ系101チームのリストを全部抽出し、一番よく使われている形(17チームが完全一致)をそのまま輸入した。我々がやったのは、パイロット固定でデッキだけ差し替えて5デッキを実測し、一番強かったこれを選んだこと。枚数の根拠は「本番で一番再現されている形だから」という統計的なもので、カード1枚単位の設計判断はしていない。だから「なぜこのカード?」は全部議論の余地があり、変更候補は§7の実戦データからすでに出ている。

6.3 「工夫」はどこにあるか(真似した部分と、していない部分)

  • 真似(輸入): 上の60枚そのもの。
  • 我々の固有部分: ①選び方(パイロット固定の差し替え実測・予測を先に書いてから測る手順・練習相手4種+本番プローブの検証) ②仕組みの特定(フリーザーの特性がなぜフーディンに刺さるか、ロケットラッシュの「展開=火力」構造、ミュウツーのサイド負債の定量)。
