§1背景 — スターミーデッキの限界と、いまのメタ

スターミー(現王者、確定レート783/793.9)の実測された限界

  • 700点を超えた瞬間に勝率52%→41%(帯別実測)。負け筋は Archaludon 16.7%・ミラー0-3・上位Lucario。
  • 「語れる要素」が測定した全デッキ中最少: 1試合に使うカード12.9枚(上位帯は15〜23)、カード種類11、攻撃役2種、スタジアム0、特性0、妨害・回収・ダメージ操作カード0。表現力指標DEXで12本中最下位(40、中央値68)。
  • 運営は評価軸に deckcrafting を名指し(§2)。スターミーは「エンジンの穴を突いた合理的なデッキ」だが、Deck 20%と記事の主役としては構造的に弱い。

メタの分析(レーティング付き全譜=我々にしか作れない計器)

800-1099帯の構成: Alakazam 29.2% / Grimmsnarl 19.3% / Crustle 13.5% / Lucario 13.2% / Archaludon 10.7%(distinct提出数で検証済み)。そして重要な発見——このメタは「強さ」で並んでいない:

  • シェアと帯内勝率の相関 ρ=−0.02。最多のAlakazamは勝率ワースト3。
  • Grimmsnarlは723体中505体(69.8%)が完全に同じ60枚。公開コードは0件(291件を実行して確認)なのに788体いる=リプレイダンプからの模倣学習で量産。8位Jakeも「データが多いから作りやすい」と証言。
  • garchompは公開評価が高くても素材が見えず133体止まり。
  • → メタは「コピー素材の可視性」のシステム。たった2種類の同一リストが全チームの35.6%。
それから — 方針転換の根拠操縦者を固定して deck.csv だけ差し替える実験で勝率が最大60pt動いた(操縦者側7ヶ月の最大改善は+13.6pt)。デッキ軸は操縦者軸の4倍広く、記事もdeckcraftingを要求している——デッキ転換はSimと記事の両方に効く。

§2調査して得た情報(外部一次情報・全て実物確認済み)

2.1 ゲーム評価の観点(審査員が見るもの)

  • 配点: Model 70%(5項目、Sim順位はその1つ=全体の約14%)/ Deck 20% / Report 10%。記事は2,000語。審査員はポケモン社3名:松尾研2名。
  • ホスト(shige)明言: 「機械学習は必須ではない。ルールベース+構造化されたレポートで十分競争力がある」。スタッフ明言: 「gameplay, deckcrafting, underlying strategic decisions が要る」「思考プロセス・試行錯誤・教訓を共有してほしい」。
  • 決勝8枠($30k×8、東京・対面)はStrategy部門の評価だけで選抜(discussion/732331)。決勝はBO3・前ゲームのログ参照可・デッキとコードは予選と別でもよい。
  • 提出済みwriteup 289件は締切まで誰も読めない(スタッフ回答で確認)。競合品質は全チーム相互に不可視——差別化は「他人が持てない材料」しかない。

2.2 コミュニティの議論(→ 我々の作戦への写像)

  • Discord初偵察(公式サーバ、ゆうじのログインで): Jack p「NNがルールを模倣するには、単純なルールは~10サンプル、複雑なルール(TR ArticunoをAlakazam戦で維持する等)は~1000サンプル要る」——我々が実測した機構(§7)を模倣コスト側から言い当てている。Santiago「ML専門家は自分が遊ばないゲームを道具で最適化する」。一部チームは「純ルールベースは審査で不利では」と忖度して自制(運営声明と矛盾)。
  • 思考時間解析(724362、73票): 場の半分はルールベース、RL+探索は1位だけ。
  • SUMIの74,634戦センサス: Grimmsnarlはシェア51%で勝率50.3%に収束(飽和)。Archaludonバブル——「上位デッキへの乗り換え」は最悪手。Oshbocker(37位)はリプレイ模倣対策にダミー提出で隠れる(going dark)。
作戦への写像コピーが支配するメタでは ①コピー元=標準化された実物リストに対して実測で選んだデッキが有利 ②複雑な対面技は模倣されない(=我々の防御壁) ③我々のルールベース路線は主流かつ運営公認。

2.3 ゲームメタ(構造の実測)

  • マッチメイキング公式仕様(726690): 4分毎・レート比例・ガウス窓・最終評価リセット無し・直近2提出が対象。
  • 帯構造: 600-800はLucario/Abomasnowの群れ、800-1000はAlakazam/Grimmsnarl中心。平衡レートは「最悪対面が濃い帯」で決まる(P9で実証)。
  • 人間メタとの断絶: AI最大勢力のAlakazamは人間City League top-cut 16に0本。AI定番のCrustle壁/LOも人間側に実質不在。

2.4 その他(議論のやりがいがある論点)

  • 較正の法則の最大例: 公式サンプル操縦者のゲージは本物の操縦者相手より+45pt甘い(§7)。りょーちんの測定にも直結する警告(較正済みゲージは§9)。
  • スコア分散は同一エージェントで±150〜400——単発のレートで判断しない。提出枠は毎日5回復・最終順位は凍結時の直近2提出のみ=枠は希少でない。
  • 公開物のタイトル自称数値は信用できない(「LB1084.5」自称の実LBが750だった等、2例確認)。

§3何を分析したか(リスト)

  1. 公開ノートブック291件を全件実行(agent()を呼び、返る60枚を分類)
  2. レーティング付き帯別メタセンサス(4,263戦/8,526側)+フィールドEV+対面行列
  3. 行動語彙の計数(上位帯と我々の「1試合でやること」の差)
  4. カードプール全数判定(2,022枚)+効果発火検査(10効果型)
  5. デッキ入替実験(操縦者を1バイトも変えず deck.csv だけ差替、5デッキ×4ゲージ)
  6. 操縦者の盲点特定と修理実験(grimmsnarlで+13〜20pt、3アンカー有意)
  7. crustleの敗因解剖(自山切れ21/21)/ 人間デッキ輸入テスト(honchkrow、失敗機構の特定)
  8. P9プローブ提出→検死→全譜54本の採掘(本番ラダーでの実地検証)
  9. 人間City League top-cut 16とAIメタの突き合わせ
  10. 外部recon: 掲示板全量・Discord・writeup可視性・マッチメイキング仕様・リーダーボード
  11. 計器の総点検(6本の欠陥特定、3本修理)+主要な根拠6件の再検証(1件崩れ→訂正済み)

§4分析の結果わかったこと(要点4つ)

  1. メタはコピー可視性のシステム。標準化された実物リストへの実測が最強の選定手段。
  2. デッキ×操縦者の結合点は少数の「盲点」に集約される。3系統を特定: ①効果由来の資源配分(修理で+13〜20pt実証) ②山を消費する特性の盲打ち ③テキスト内打点(damage欄0)。
  3. 他人の操縦の実ラダー値は我々の操縦者には転移しない(−23pt〜+42ptの双方向)。選定は必ず「我々の操縦者を載せた実測」で。
  4. ゲージには嘘がある: 公式サンプル由来Lucarioゲージは+45pt甘かった。実ラダー検証済みの較正ゲージに世代交代(P9実測セルと14.0%≈15.4%で一致)。

§6いま試しているアクション — なぜtarountulaを選んだか(正直な経緯)

6.1 選定の方法 — 構成は「設計」ではなく「輸入+選抜」

このデッキは我々が1枚ずつ組んだものではない。実ラダー800-1099帯の全譜からtarountula系101体のリストを抽出し、最も再現されている形(17体が完全一致の最頻出形)をそのまま輸入した。我々がやったのは構築ではなく選抜——操縦者を固定して deck.csv だけ差し替え、5デッキ×4ゲージで実測して最高値を出したこれを選んだ。枚数の根拠は「実ラダーで最も使われている形」という統計的根拠であって、カード単位の設計判断はしていない。だから「なぜこのカード?」は全部議論の余地があり、変更候補は§7の実戦データから既に出ている。

6.3 工夫はどこにあるか(真似と、真似でない部分の区別)

  • 真似(輸入): 上の60枚そのもの。
  • 我々の固有部分: 選定方法(操縦者固定の差し替え実測・事前予測の凍結・4ゲージ+本番プローブの検証鎖)と、機構の特定(Repelling Veil×Alakazamの因果、Rocket Rushの盤面スケーリング、Mewtwo負債の定量)。
  • つまり「なぜ〇〇を選ばなかったのか?」への現状の答えは「最頻出形に含まれていなかったから」しかない。ここから先(1枚単位の設計)を、実戦データを根拠にチームでやりたい。

§8提案と、りょーちんに聞きたいこと

提案(tarountula-v2): §7の実戦根拠に基づき、①ミラー勝者の改良要素(Ultra Ball/Mimikyu)の検証 ②Mewtwo 2→1or0 ③たね/Proton増量 ④操縦者の2行修理+型対応エネ配分——を個別に較正ゲージでスクリーニング(全て事前登録つき)→通った束だけでプローブ再提出→その実測で8/13-16の凍結を設計。

議論したいこと(4つ)
  1. 凍結設計の哲学: 「レート最高(王者starmie維持)」vs「記事で守るデッキ(tarountula-v2)」——どちらに張る?(1枠ずつの両にらみ案もあるが、最終2枠は「ベスト×2」が事故に強いというのが従来合意)
  2. §6.2の構成で「なぜ〇〇を入れない/削らない?」——ポケカ側の直感での指摘が欲しい(例: Mimikyuの役割、Ultra Ballの手札コストとAriana補充の相性、Mewtwo全抜きのリスク)
  3. りょーちんのStarmie系agentで得た技法のうち、TR系デッキに移植価値があるもの
  4. この資料の形式で足りない情報(次回から改善する)
