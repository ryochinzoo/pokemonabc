## 2.5 ★先行 futility プローブ(本測定より前に走らせる。停止規則も凍結)

**腕B・フーディンセルのみ N=600**(約18分)。**判定規則は一切変えない。**

理由は算数である。他4セルが**登録した予測上限を同時に取った**としても、採用ライン 61.70pt に
届くにはフーディンセルが **69.26% 以上**必要になる:

    .2247×55(オーロンゲ上限) + .1572×90(イワパレス上限) + .1537×45(メガルカリオ上限)
      + .1246×38(ブリジュラス上限) = 38.16pt
    → 必要なフーディン = (61.70 − 38.16) / .3399 = 69.26%

**停止規則(凍結)**: フーディンセルの **95%上側信頼限界 < 69.26%** なら、
**他の全セルが同時に上限を取っても採用は算数的に不可能** → 本測定を起動せず、
デッキ側の修正に切り替える(D70 が「全セルが登録上限を同時に取っても +3.53pt < MDE。
どう転んでも検出不能」で測定を止めたのと同じ論法。`decisions.md` D70)。

N=600 の根拠: 予測中点 65% での 95%UCB は N=400 で 69.67%(**発火しない**)、
N=500 で 69.18%、**N=600 で 68.82%**。500が損益分岐なので余裕をみて600を取る。
⚠ T7レンズAは「N=400で発火する」と述べたが、**検算したところ発火しない**。Nを600に訂正した。

**発火した場合にすること**: 本測定は起動しない。デッキを直してから再登録する。
**発火しなかった場合**: 本測定を予定どおり全量走らせる。
どちらの場合も、このプローブは**層S(引用禁止・採否には使わない)**であり、
採否判定はあくまで §3 の規則で行う。

  1. **①かつ②** → 採用候補。ゆうじに**提出承認を求める**(T4懐疑パスを前置)。
  2. **①だが②でない**(効果はあるが採用域未満) → **昇格せず。提出しない。記録のみ。**

- **+2ptは魔法の壁ではない**。跨いだかだけで判定せず、CIを必ず併記する(playbook §1)。

## 5. 反証テスト(playbook §1。結論を書く前に必ず確認する)

⚠ **初版は「エースバーンの加速機構が効いたか」を本測定で反証しようとしていた。これは不可能である**
(§8 の訂正ログ参照)。理由は3つとも決定的:
①**腕Bは腕Aとデッキ17種＋ロジック4件が違う束**なので、フーディンセルが低くても
「エースバーンが効かない」とは言えない(エースバーン +10 / デッキ入替 −40 でも同じ観測になる)。
②`bench.py` は**発火率を一切出さない**。登録した手順で収集できない証拠を判定条件に書いていた。
③予測区間(55〜75%)のもとで「反証(≤65%)」の事前確率は 50%、「支持(≥75%)」は 2.5%。
**20倍偏った検定**で、私が既に書いている結論をほぼ自動的に返す。

**訂正後の形 — 2つに分ける。**

### 5-a 束レベルの反証(本測定で実行可能。これを主の反証テストとする)

**主張**: 「ドメイン知識で組み直したデッキ＋4ロジックの束は、現王者より強い」。
- **反証となる観測**: Δ ≤ 0(§3 の分岐3-4)。
- **加えて必ず確認する**: 束が**どのセルで**負けたか。§4 の予測区間の外に出たセルがあれば
  T1 を発火させ、較正監査(重み・ゲージ・較正法則の再点検)に回す。
- **この反証は機構に言及しない。** 束の寄与は分離できない(§1)ので、機構の話はしない。

### 5-b 機構レベルの観測(層S。**引用禁止・採否に使わない**)

「エースバーンの加速機構は発火しているか」は**別の計器**で見る。本測定とは分けて走らせる:
- `V3_SELECT_TRACE=<path>` を立てた**層Sの側走行**(フーディン相手 N=100)で、
  L1〜L4 の発火率を直接数える。出力は `~/Documents/products/pokemonabc-runs/mastercontrol_trace/`。
- **本測定のプロセスでは絶対に立てない**(トレースI/Oが時間予算を汚す)。
- 記録するのは**発火率だけ**で、勝率とは結びつけない。
  「機構が一度も発火していない対面があれば、その対面のΔにその機構は寄与していない」
  という**否定形の帰属にのみ使う**(playbook §1: 発火していない機構の勝率差を語らない)。

**既取得の発火率**(2026-08-10、`verification/mastercontrol_probe.py`、層S):
