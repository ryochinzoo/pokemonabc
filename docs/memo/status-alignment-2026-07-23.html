2. 前提転換: D27「較正の法則」— すべての判断の土台

発見1(較正の法則): デッキを固定して操縦者だけ入れ替えて測ったところ、 族内ベンチ(自分のパイロットが相手デッキも操縦する測定)の誤差は「実際の相手操縦者と自分の操縦者の実力差」に比例することが3アーキタイプで一致した: steel相手+62pt / 公式Lucario相手+41pt / りょーちんagent相手+8pt(各N=300)。 つまり族内ベンチが測っていたのは「相手のデッキを自分が操縦したときの勝率」で、上位帯ほど無意味になる。

発見2(決定打): Kaggle公式サンプルエージェント(Lucario版、997 Copy&Edit)が実ラダーの対戦相手そのものだった — 実ラダーで遭遇したデッキリストと60/60枚完全一致。遭遇率1位(現重み49%)の対面をローカルで完全再現できた。

帰結: 過去5件の介入棄却は「実在しない優勢(ローカル84.7%等)を前提に的外れな対面を磨いていた」で説明がつく。 以後、効果量の判定は必ず較正済み族外ゲージで行い、族内ベンチはスクリーニング専用。 この発見自体がwriteup §3(検証基盤)の主砲。前向き検証も済んでいる(T1: 予測37.0% vs 実ラダー実測35.0%、族内の含意84%は+49pt外れ)。

4. D39: E1先行ゲートの中身 — 何を確認して、何を留保したか

E1とは何か

介入: -1 Deluxe Bomb[1167] / +1 Maximum Belt[1158](デッキ1枚差のみ、パイロット凍結=main.pyは王者とバイト同一をcmpで証明済み)。

1対1は制約であって設計判断ではない: 両方ACE SPECでデッキに1枚のみ。純増ではなくトレードオフとして登録。

機構仮説: Beltは「相手のバトル場がexのとき、装着ポケモンの攻撃+50」。較正済み4ゲージの主力アタッカーは全てex(=CEW測定面の100%に適用可)。 特に対Mega Lucario ex(HP340): 現行はNebula 210+Jetting 120=330で10点不足のところ、Beltが乗れば2発KO線を跨ぐ。

失うもの: Bomb=被弾時に攻撃側へ120ダメカン。D36は「対Archaludon資産(120+Nebula210=330>HP300)」と評価していた。

先行ゲート結果(プローブ30戦: belt10+延長10+base10、7/23)

ゲート結果中身
(1) 盤面付与PASS(ぎりぎり)Belt盤面付与3/10=基準「3以上」ちょうど。延長も3/10(計6/20=30%)
(2) 貼付先記録(killなし)Mega Starmie ex×4 / Staryu×2=1/3が死に先。加えて新観測: Beltが手札の捨てコスト(Ultra Ball等)として盤面到達前に燃えたゲーム5/20=25%(Bomb基準0/10)
(3) +50機構確認Jetting Blow(120)+Belt→ΔHP=170が4イベント(対Mega Lucario ex)。条件節も両方向検証: 非ex相手は+50なし/Belt無しNebulaは210ちょうど×11。「Mega Pokémon exはBeltの{ex}判定を受けるか」というエンジン疑問=YESでクローズ
⚠ 通過判定の正直な開示(D39+追記)
改訂2で登録した厳格形(Nebula 210+Belt→ΔHP=260)は20戦で0件だった。原因はas-piloted: Beltつき個体はエネ3個が揃う前にJettingで殴る局面が支配的で、Nebula+Beltの同時イベントが生成されない。 判定の根拠: 登録のkill条件は「+50が観測できなければ即kill」であり+50は4イベント観測済み=不発火。「延長後も厳格形0件」という分岐は登録に存在しない空白で、有効に残っている登録kill基準へのフォールバックで解決した(=killの上書きではなく文言の範囲内の判定。ゆうじの「ほんとにそれでいい?」を受けた再監査で確認、D39-追記)。
再審フック: 本測定でLucario成分が伸びなければ、この通過判定自体を「甘さの候補」として再審する。

副産物(counterfactual実測): Bombの起爆は2/10ゲーム(盤面到達4/10のうち)。「対Archaludon資産330線」の実効はas-pilotedで期待0.2発/ゲーム — Bomb喪失を過大に恐れる必要はなさそう。ただしプローブ相手はLucarioなので、Archaludon対面の起爆率は本測定の対面別で再確認。
