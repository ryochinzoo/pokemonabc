## 2. 何が起きたのか(機構、12戦のトレースから)

修理の中身は「テキストにしか書かれていない打点をAIに見せる」こと。ワナイダーの技
**ロケットラッシュ = 場のロケット団の数 x 30ダメージ** は、カードのダメージ欄が0なので、
AIはこれを「0点の技」と誤認して53戦で一度も撃たなかった。

修理後(12戦):
- ロケットラッシュ発射 **45回** (3.8回/戦)
- 発射時の盤面(ロケット団の数)の分布: {2: 1, 3: 2, 4: 2, 5: 5, 6: 35} ← **盤面6体が35回 = 78%**
- 見積り打点の分布: {60: 1, 90: 2, 120: 2, 150: 5, 180: 35}
- リーサル(とどめ)検出の成立: **45/45回**(修理前は永久に不発)
- 退却の選択: 1.92回/戦(修理前 3.2回/戦)
- エネルギーを貼った先: {"Team Rocket's Spidops": 39, "Team Rocket's Wobbuffet": 32, "Team Rocket's Murkrow": 31, "Team Rocket's Articuno": 7, "Team Rocket's Tarountula": 3} ← フリーザーは0.58回/戦(修理前 1.7枚/戦)

## 3. オーロンゲに勝てるようになった理由(カードの数字)

- **マリィのオーロンゲex: HP320、弱点【草】**
- **ロケット団のワナイダー: 草タイプ**
- ロケットラッシュの打点 = 盤面の数 x 30、弱点で **x2**

| 盤面 | 素点 | 弱点x2 | ブレイブバングル(+30、弱点計算の前)込み |
|---|---|---|---|
| 4体 | 120 | 240 | 300 |
| 5体 | 150 | 300 | **360 = HP320を一撃KO** |
| 6体 | 180 | **360 = 一撃KO** | 420 |

→ v2でブレイブバングルを1枚から3枚に増やしたのは、**一撃KOに必要な盤面を6体から5体に下げる**ため。
実測でも盤面6体に78%到達しており、この勝ち筋が日常的に発火している。

## 4. 逆に悪化した理由(仮説、要検証)

メガルカリオ系(HP340)とブリジュラス系(HP300)には弱点が乗らず、盤面6体+バングルでも**天井210**で届かない。
そこへ v2 で **ロケット団のミュウツーex(HP280、打点160)を2枚とも抜いた**結果:
- 良い面: 倒された時にサイドを2枚取られる負債が消えた(本番53戦では献上サイドの33.7%がこのカード)
- 悪い面: **唯一の高HPの受け皿と、唯一の高打点を同時に失った**
→ 対メガルカリオが 19.0% から 8.0% へ有意に悪化。サイド負債の削減より、耐久と打点の喪失が上回った。
