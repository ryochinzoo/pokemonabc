**差 = +13.0pt、95%CI [+6.22, +19.78]。** 事前に凍結した点予測(+9.5pt)を**上回った**。

|---|---|---|---|

**符号が反転した。19.3%の対面を計器から落としていたせいで、
我々はデッキ判断の向きを間違えて記録していた。**

v2 が勝つのは オーロンゲ(+13.0pt、重み0.2247)と イワパレス(+1.75pt)、
負けるのは メガルカリオ(−9.0pt)と ブリジュラス(−4.75pt)。

### 5.5.3 それでもデッキ転換はしない(理由は1つだけ)

**+1.38pt は、測定前に凍結した提出基準(MDE 2.44pt)を超えない。**
基準は測定を始める前に文書化し、チームの承認を得ていた。**超えなかったので適用する。**

これは「v2 が悪い」という判断ではない。**「−2.70pt という記録は誤りで、正しくは +1.38pt。
ただし提出を動かす大きさではない」**が、この測定の言えることのすべて。

### 5.5.4 あなたのQ5(エネ構成)への反証

「v2化がエネルギー構造を救う唯一の物理的解答」という主張は**逆**である。

| | v2 | P9(pilotfix) |
|---|---|---|

**v2 にも ソーナンス(超無)×1 と ヤミカラス(悪無)×2 が残っている。**
v2 は基本超3枚を抜くので、あなたが「確率的に大欠陥」と指摘したその依存を**深くする**。
(v2 が勝っているのは、この欠陥にもかかわらず、である。)

### 5.5.5 ★我々のコード側に新しい欠陥が見つかった(あなたの指摘の副産物)

**ダメージ見積り関数に「どうぐ」の項が一切なかった。**
素点 → スケーリング → 弱点×2 → 抵抗−30 の順で計算しており、バングルの+30を**知らない**。

**帰結: 場5体+バングルで実際には360出て オーロンゲexを倒せるのに、
我々の操縦者は300と見積もり、「倒せる」と認識しない。**
v2 はバングル3枚(P9は1枚)なので、この取りこぼしが3倍起きる。

→ **上の測定(v2 48.5%)は、v2 を過小評価した値である。**
   提出するのも現行操縦者なので採否の判断としては正しい値だが、**v2 の上限はこれより高い。**

### 5.5.6 「3修理」を測らない理由(算数)

あなたが推した costfix / I1 / VETO は、**事前登録した予測が +0.31pt**(5面重み)。
一方、この規模の測定で検出できる最小効果(MDE)は **約3.65pt**。
**登録したすべてのセルが同時に上限を取っても +3.53pt で、MDE に届かない。**
どう転んでも検出できないので、測定しない。実装はトグル付きで残してある。
