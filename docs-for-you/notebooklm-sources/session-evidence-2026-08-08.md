## 3. 記録済み数値の訂正(重み付けの誤り)

「操縦者修理 +4.1pt / デッキ差分 +0.1pt(実質ゼロ)」という記録は **5面加重(カバレッジ85.9%)**で計算されていた。
その5面には**オーロンゲ = 族内ゲージ(自分の操縦者が相手デッキを回す)が19.3%の重み**で入っていた。
族内ゲージは判定への使用が禁止されている(過去の実測で +8〜+62pt 甘い)。

族外ゲージだけの4面(カバレッジ66.6%)で同じ実測値を再計算すると:

| | P9素 | 修理のみ | 修理+v2デッキ | 修理の効果 | デッキ差分 |
|---|---|---|---|---|---|
| 5面(族内込み・**記録された数値**) | 57.32 | 61.41 | 61.46 | **+4.09pt** | **+0.04pt** |
| **4面(族外のみ・正しい軸)** | 64.81 | 66.75 | 64.05 | **+1.94pt** | **−2.70pt** |

**デッキ差分の符号が反転する。**「v2化は実質ノーコスト」という前提は成立しない。

## 5. 「マント付きワナイダー HP230 の壁」説の棄却根拠(5点)

1. **ヒーローマントは v2デッキに既に1枚入っている。** −11.0pt(19.0%→8.0%)を測った両方の腕に入っていた。
   = 変数ではなく定数。「入れて壁を作る」で回復する量は定義上ゼロ。
2. **マントを貼ると相手はワザを切り替える。** 較正済みゲージの攻撃選択は相手の現在HPを見て、
   リーサルなら満点・非リーサルなら `ダメージ/HP` で減点する。
   HP230に対し はどうづき130 = 1,697点 / メガブレイブ270 = 2,282点 → **メガブレイブを選ぶ**。
   マント無し(HP130)なら はどうづき2,262 > メガブレイブ2,082 で逆転。
   **一撃技を別の一撃技に切り替えさせるだけで、稼げるターンはゼロ。** 差は455〜585点で盤面によらず覆らない。
3. **相手デッキは「プレミアムパワープロ」を4枚積む**(「このターン、自分の闘ポケモンのワザは
   相手のバトルポケモンへのダメージ+30」、グッズなので同一ターンに重複可)。
   はどうづきの実効打点は **130 / 160 / 190 / 250**。4枚重ねれば230を素で一撃。
4. **相手も自分のヒーローマントを1枚積み、メガルカリオに貼る**(常用440HP)。
   さらに**マントを貼った体はブレイブバングルを持てない**(どうぐ枠は1匹1枚)ので、
   **貼った瞬間に自分の打点が 210 → 180 に落ちる。**
5. 壁テックは以前**反証条件「較正ゲージ vs v2 が N=200 で30%以上」つきで棄却**されていた。
   **実測 8.0%** で、構造判断が22ポイント差で持ちこたえた。

## 7. 掃引(約2,940戦)を走らせなかった理由

独立レビュー3本(統計 / 実装 / 前提)が独立に「設計どおりには走らせるな」と判定した。

1. **検出力が予測に届かない。** 4面合成の最小検出可能効果は 2.67pt。
   一方、自分の各セル予測が含意する合成値は **+0.40pt(検出力 6.9%)**。
   両方の床セルが予測上限を取っても合成は最大 +1.79pt で届かない。
   +1.0pt を80%で見るには約7.4倍(8,900戦/腕)必要。
2. **kill基準が壊れた計器。** 「合成が0以下なら棄却」は真値0で **50%**、真値+0.40ptでも **34%** 発火する点推定ゲート。
3. **昇格先が存在しない。** 宣言した層Bの計器(CEW)は、外部データにχ²=37.68で棄却された重みのまま。
   さらに CEW の4ゲージと本掃引の4ゲージは1本しか重ならない。
4. **3介入を1腕に束ねていた。**
   特に **VETO は探索決定を 131→117 = 10.7% 削る**。探索層は対照実験で **+13.62pt** と測られた最大の資産で、
   価値が一様なら −1.46pt。予測される利得と同オーダー。
5. **オーロンゲの族内ゲージは我々の探索を両側で回す**ため、合成から除外される300戦のセルが
   所要時間の **70〜90%** を食う設計だった。
6. **ブレイブバングルの +30 は「相手のバトルポケモンが ex」のときのみ。** 非exの相手には0。介入の天井が想定より低い。

## 8. このセッションで踏んだ罠(方法論の記録)

1. **自己対戦で対照実験を組み、3時間26分を溶かした。** 自己対戦は両側が探索を回すため、
   外部ゲージ相手(280〜660ms/戦)の数十倍かかる。→ 決定レベルの突合(数分)に差し替え。
2. **zsh は クォートしない `$var` を単語分割しない。** `env $vars cmd` 形式のアブレーションは
   **先頭のトグルしか適用されず、しかも数値は正常に出る。**
3. **掃引ドライバが環境変数7つのうち3つしか潰していなかった。**
   探索無効フラグが漏れると VETO が完全な no-op になり、ログは正常に見える。
4. **ATTACKログの type を 3 と決め打ちして全ゲーム0回になった。** 正解は 15 で、既存の健全な実装に書いてある。
   = 「既存実装を読まずに書き直す」の再発。
5. **反証条件を装った確実な勝ち。** 「メガルカリオが30%を超えたら私の負け」と登録したが、
   真値8%・N=400 では **16.2σ / P≈2×10⁻⁵⁹**。しかも既に8.0%で棄却済みの閾値の再利用で情報量ゼロ。
